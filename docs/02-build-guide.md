## 01 部品表

回路図 `AmTransmitter.kicad_sch`の記号に対応させた一覧。全体を1枚の基板（100×100mm・2層）に載せる。基板に載らないのは BT1、SW1〜SW3、Q2（2SK4017）と、その足元に付ける R9・C5・J7。コイルの巻き方は 04章、判断の根拠は別資料の設計判断記録を参照。

コネクタとテストポイント：

- **電源** — J5 = バッテリー（XT30）、J4 = 主電源スイッチ SW_Power（XH 2ピン）、J8 = NJW4190M。
- **ジャンパ** — J11 = ドライバのコレクタ給電（+8V）、J12 = BP5293-33 → XIAO 3V3（USB 書き込み時は外す）、J13 = 終段のドレイン給電（Mod → L8）。
- **信号** — J1〜J3 = 押しボタン SW1〜SW3、J6 / J7 = 2SK4017 への引き出し（基板側 / FET 側）、J9 = マイク、J10 = LCD、**J14 = RF 出力**。
- **テストポイント** — TP2 = Mod（変調器出力）、TP3 = +8V、TP5 = ゲートバイアス、TP6 = BP5293-33 出力、TP9 = +3.3VB、TP1 / TP4 / TP7 / TP8 = GND（TP4 は R28、TP8 は R37、TP7 は R36 の隣）。

### 発注時に効く指定

値だけで選ぶと失敗する部品をまとめた。**ここに挙がっていない部品は、値と一般的な耐圧（RF 系は C0G 50V、電源系は電圧の2倍）で選んでよい**。

サイズは**メトリック表記**で統一してある — `1608` = 1.6×0.8mm（インチ 0603）、`2012` = 2.0×1.25mm（インチ 0805）、`3216` = 3.2×1.6mm（インチ 1206）。部品によっては型番やシリーズ名にインチ表記が入っている（TDK SIMID 0805-F など）ので、発注時は実寸で確認すること。

| 部品 | 指定 | 理由 |
|---|---|---|
| C54〜C59 | C0G(NP0) **100V** | LPF 中央のノードに 33Vp・0.9Arms がかかる。50V 品では余裕がない。サイズは 1608 / 3216 のどちらでも電気的に成立する |
| C52 / C53 | C0G **100V**（トリマも 100V 級） | ここは LPF 入口と同じ 50Ω 点なので、変調ピークで **24.5Vpk**。C52 には約 0.8Arms も流れる |
| C50 | C0G 50V / **3216**（2012 まで可） | かかる電圧は 1.3V 前後なので耐圧は不問。効くのは電流で、L10 と直列なので **基板上で最大の 1.31Arms** が流れる。ESR の発熱（`I²×ESR`）がパッケージの放熱能力を超えるので **1608 以下にしない**。なお C0G の 0.01µF は体積を食うので、実際には 2012 / 3216 しか選択肢がない |
| C42 | **1608** C0G 2200pF | 自己共振 138MHz を利用して 144MHz でほぼ 0Ω にしている。サイズが変わると共振点が動く |
| RF 系のコンデンサ全般 | **C0G(NP0) 必須** | X7R は損失と電圧係数で使えない（[回路設計書 08章](01-circuit-design.md#08-出力-lpf-の設計)） |
| C41 / C53 / C61 | VHF 用セラミックトリマ | Q が低いとそのまま損失になる。C53 は上記のとおり 100V 級。**トリマは 0pF から始まらない**ので、可動域は最小容量込みで見積もる（C39 はこれが原因で DNP になった） |
| L1〜L3 / L4 / L9 | **2012** の巻線（ワイヤワウンド）型 | 積層型は 145MHz では共振点のはるか上で、抵抗として振る舞う（[回路設計書 07章](01-circuit-design.md#07-終段の整合回路)） |
| L5（RT8250） | **飽和電流 2A 以上** | 8V レールのピークが 1.47A |
| C4 / C1 / C9 / C10 / C18 / C19 / C26 / C27 / C47 | 耐圧 **25V 以上** | 電池電圧（最大 17V）とチャージポンプ出力 17.4V が直接かかる |
| C26 / C27 / C47（セラミック） | DC バイアス特性に注意 | 25V 品に 17V を加えると実効容量が半分以下になることがある。35V 品か1サイズ大きいパッケージを選ぶ |
| C32（470µF） | **低 ESR** | 700Hz・0〜1.5A の負荷変動を支える。汎用電解だと変調ピークで 8V レールが落ちる（[回路設計書 09章](01-circuit-design.md#09-電源系統)） |
| C9 / C10 / C18（NJW4190M） | 低 ESR | チャージポンプのフライング／入出力。データシート指定 |
| F1 | 保持電流 1.85A 級 | 60°C では定格の 65〜70% しか流せない。1.0A / 1.35A 品は変調ピークで誤動作する |
| RV1 | 10kΩ <strong>多回転（25回転）</strong>半固定 | Vgs(th) を 0.1V 単位で追い込むため。3端子（ポテンショメータ）結線で使う |
| 検波プローブのダイオード | 1SS270A（DC 60V） | 逆電圧が 49V に達する。1SS106 / BAT43（ともに 30V）では足りない |

## 02 基板（v0.1）

電源・MCU・変調器・RF 部をすべて1枚に載せる。回路の理由は回路設計書、立ち上げは調整手順書。

### 基板（v0.1）

電源・MCU・変調器・RF 部をすべて <strong>1枚の基板（100×100mm・2層）</strong>に載せる。部品は裏面、表面はほぼ全面 GND ベタ。

- <strong>RF の配線は裏面のマイクロストリップ、基準面は表面の GND ベタ。</strong>表面に配線を通すときは RF の通り道の上を避け、両側に GND ビアを並べる。
- <strong>GND ビアを密に打つ。</strong>RF のシャント C・エミッタのバイパス・Q4 のタブの GND パッドは真横にビア、基板の縁と RF 部の周りは 5mm 間隔程度。RF のシャント C の GND パッドはベタ接続（サーマルリリーフにしない）。
- **インピーダンスの低いノード（50Ω 系・ゲート・ドレイン）は太く短く**（1mm 前後）。高いノード（ドライバのコレクタ、約 280Ω）は細いままでよい — 容量を増やさない。
- **段間は 0Ω（R28 / R37 / R36）で切り離せるようにし、隣に GND のテストポイント**（TP4 / TP8 / TP7）を置く。NanoVNA のピグテールはここに当てる（調整手順書）。
- <strong>変調器（U2・J6）は RF 出力 J14 から離す。</strong>オペアンプの入力は RF が入ると整流されて出力がずれる。ピン直近のパスコン（C2 / C3 / C25）と、Mod・+8V の基板側の 1000pF（C66 / C67）で守る。
- <strong>RF 出力 J14 は RG-174 の直付け。</strong>網線はピッグテールにせず、網線パッドに広く付ける。ケーブルは基板に固定する。

### 実装の注意

- <strong>SOT-89 の放熱。</strong>終段の損失は搬送波時で約 0.7W（試作で電源電流から換算。設計時の見込みは 1.5W）と、通常運用では小さい。それでも異常時に跳ね上がるので経路は省かない。SOT-89 は熱抵抗が高いので、タブ下にベタ銅箔＋サーマルビアは必須です（v0.1 基板はタブ下とその周りに格子状のビア）。ここを軽く見ると変調ピークで素子温度が限界を超えます。**目標は 10°C/W 以下** — 変調基準が 3.3V に張り付いて 8V 連続になっても損失 6.3W / 温度上昇 63°C で収まり、素子を失わずに済みます（[回路設計書 03章](01-circuit-design.md#03-変調器m3の回路図)）。
- <strong>8V ラインにフェライトビーズ + 0.1µF。</strong>降圧DC-DC のインダクタは RF 部から離します。

## 03 2SK4017 の取り付けとケース

変調器のパス素子 2SK4017 は基板に載せず、ケースの側板に取り付けてリード線で基板とつなぐ。

### 2SK4017 の引き出し

**ケースの側板に取り付けてリード線で基板とつなぐ**。基板側 **J6** と FET 側 **J7**（どちらも 4ピン）の間を、4本より合わせた線で結ぶ。

| ピン | 基板側 J6 | FET 側 J7 | 線 |
|---|---|---|---|
| 1 | +8V | D（C5 の片側） | AWG22〜20。最大 1.5A |
| 2 | オペアンプ出力 | R9 470Ω → G | 細線で可 |
| 3 | GND | C5 の GND 側 | 細線で可 |
| 4 | Mod（C8・R8・TP2） | S | AWG22〜20。最大 1.5A |

> [!WARNING]
> **ソースフォロワを配線で伸ばすときの約束**
>
> - <strong>R9（470Ω）はゲートの足に直付け。</strong>基板側に残して長い線でゲートへ行くと、線のインダクタンスとゲート容量で VHF の寄生発振を起こしやすい。
> - <strong>C5（0.1µF）を FET の足元で D–GND。</strong>GND はケースではなく J7 の pin3（4本目の線）に取る。アルマイトの側板は本体と導通していないことがある。
> - <strong>帰還（R8）と C8 は基板側の Mod ノード。</strong>線の抵抗による電圧降下（1.5A で数十 mV）もループが補正する。線のインダクタンスはループに入るが、高域は C6 でオペアンプ出力から帰還しているので影響は小さい。
> - <strong>4本をより合わせて 10cm 以内（できれば 5cm）。</strong>RF 基板とアンテナコネクタの近くを通さない。
> - 基板側 J6 の pin3 は R5 やオペアンプの GND ではなく **8V 電源側の GND** に寄せる。J6 は 8V レールの出力コンデンサの近くに置く。

### 2SK4017 の取り付け

損失は最大約 3W（3.5W で設計）、放熱器側に許される熱抵抗は 12°C/W 以下（[回路設計書 03章](01-circuit-design.md#03-変調器m3の回路図)「放熱の見積もり」）。

- <strong>取り付け。</strong>ケース側板（1mm）の内側に 2SK4017、**同じ位置の外側にヒートシンク**を当て、M3 ネジ1本で3枚を共締めする。グリスは2面とも。板厚方向の熱抵抗は 0.05°C/W 程度で無視でき、1mm 板で熱が横に広がらない問題はヒートシンクが受け持つ。**ヒートシンクはカタログ値 8°C/W 以下**（40×40mm・フィン高 20mm 前後が目安）、フィンは縦向き。放熱用両面テープは使わない。
- <strong>絶縁は不要。</strong>TO-220SIS（フルモールド）なのでネジもヒートシンクも GND 電位でよい。
- <strong>確認。</strong>連続 30分で、ヒートシンクの根元（素子の真裏）が **60°C 以下**なら合格（チャネルはおよそ +25°C 以内）。

### ケースと GND

- <strong>ケースはアルミにして GND につなぐ。</strong>シールド（アンテナから戻る RF を変調器・MCU に入れない、終段の高調波を外へ漏らさない）と、2SK4017 の放熱を兼ねる。
- <strong>主な接地点は RF 出力のパネルコネクタ。</strong>RG-174 の反対側をパネル取付の BNC / SMA につなぎ、そのフランジでケースに落とす。
- <strong>基板は四隅の取付穴（H1〜H4、GND）から金属スペーサでケースに落とす。</strong>高周波では短く多点でつなぐほうが効く。
- <strong>大電流の戻りはケースに流さない。</strong>ドレイン電流（最大 1.5A）と電源の戻りは配線と基板の GND で返す。ケースは同じ電位にそろえるだけ。
- <strong>アルマイトや塗装は絶縁体。</strong>接触部は削るか菊座金で食い込ませる。**フタと側板も本体と導通させる**（浮いたままだとシールドが大きく落ちる）。
- <strong>ケーブルは固定する。</strong>RG-174 と 2SK4017 への4本の線は、はんだ部分に力がかからないよう基板やケースに固定する。

## 04 手巻きコイルの製作

手巻きにする 8本はすべて空芯で自作する。**φ0.65mm ポリウレタン線（2UEW、外径 0.694mm）を φ5mm（L10 / L14 は φ3mm）の丸棒に巻く**前提で定数を出した。平均直径は `心棒径 + 0.65mm`。巻数と巻き長はホイーラーの式による。チップで代用するコイル（L1〜L3、L4、L9）はここには含めない。使い分けの判断は次項を参照。

| 記号 | 用途 | 心棒 | 目標 | 巻数 | 巻き長 | ピッチ | 密着巻き時 |
|---|---|---|---|---|---|---|---|
| L8 | 終段ドレイン給電 | φ5 mm | 0.47 µH | 14 T | 10.6 mm | 0.75 mm | 0.50 µH |
| L6 | ドライバ出力整合（可変） | φ5 mm | 120 nH | 6 T | 6.9 mm | 1.15 mm | 169 nH |
| L12 | 出力 LPF 中央 | φ5 mm | 78 nH | 4 T | 3.9 mm | 0.98 mm | 95 nH |
| L11 / L13 | 出力 LPF 両端 | φ5 mm | 71 nH | 4 T | 4.5 mm | 1.13 mm | 95 nH |
| L7 | ドライバ入力整合（可変） | φ5 mm | 56 nH | 4 T | 6.4 mm | 1.61 mm | 95 nH |
| L14 | 終段入力整合（可変） | **φ3 mm** | 33 nH | 4 T | 4.7 mm | 1.18 mm | 48 nH |
| L10 | 終段出力整合（可変） | **φ3 mm** | 14 nH | 2 T | 2.1 mm | 1.05 mm | 17 nH |

手巻きにするのは 8本で、必要な線材は総延長で約 87cm（リード分込み）。10m 巻きを1本買えば足りる。心棒は **L10 と L14 が φ3mm、残り6本は φ5mm**。丸棒はドリルの軸で代用できる。

可変コイルの目標値は出発点で、最後は実測で決まる。試作で追い込んだ結果は **L6 ≈ 116nH**（設計 120nH）、<strong>L10 ≈ 14.1nH（リード込み）</strong>（設計 14nH）。L10 は見た目がかなり広がった状態で合ったが、リードのインダクタンスが加わっているためで、値としては正しい。L7 / L14 は大信号で決めるので未確定（[調整手順書 04章](03-bring-up.md#04-試作で決まった値調整の出発点)）。

> [!WARNING]
> **小さい値のコイルは心棒を細くする**
>
> - 目標が小さいコイルを φ5mm で作ると、巻数が足りないぶんを**ピッチを広げて稼ぐ**ことになる。線径 0.694mm に対して隙間が線径以上に開くと「ほぼバネ」になり、手で触れただけで形が変わってインダクタンスが動く。
> - <strong>L10（14nH）</strong>は φ5mm だと 2回でピッチ 3.2mm（隙間が線径の 3.6倍）。**φ3mm で 2回・ピッチ 1.05mm** にすると隙間は線径の半分に収まる。
> - <strong>L14（33nH）</strong>も同じ問題で、φ5mm・3回だとピッチ 2.01mm（隙間が線径の 1.9倍、密着巻きの 2.9倍まで引き伸ばすことになる）。**φ3mm・4回・ピッチ 1.18mm** なら隙間は線径の 0.49倍で、引き伸ばし率も 1.7倍に収まる（ADR-018）。
> - 可変コイルは伸縮させて追い込む前提なので、**目標値が可動域の真ん中あたりに来る**のが望ましい。L14 は φ3mm・4回にすることで、目標域 29〜35nH が巻き長 4.35〜5.59mm という扱いやすい幅に対応する。

> [!WARNING]
> **L8 に 1µH は要らない**
>
> - チョークに求められるのは「145MHz でドレインの負荷 3.5Ω に対して十分高いこと」だけ。**0.47µH でも 471Ω = 134倍**あり、負荷への影響は 0.7% にとどまる。
> - 長いソレノイドでは `L = µ₀ N A / p` なので、**巻数は L に比例し、直径の2乗に反比例**する。1µH のままだと φ5mm で 27回・20mm になるが、0.47µH なら **14回・10.6mm** で済む。
> - 線長は 479mm → 248mm、DCR は 24.8mΩ → 12.9mΩ。自己共振も 331MHz → 482MHz と遠ざかる。
> - 心棒を φ10mm にして 1µH のまま 11回にする手もあるが、直径が増えるぶん磁界が広がって出力 LPF と結合しやすい。**φ5mm で統一するほうが実装が楽**。
> - C43（0.01µF）との直列共振は 73MHz。ここには何も存在しないので問題ない。

### チップと手巻きの使い分け

チップは **2012（インチ 0805）の巻線（ワイヤワウンド）型**に限る。積層型は不可（[回路設計書 07章](01-circuit-design.md#07-終段の整合回路)）。判断はコイルに流れる**電流**と、**実測で追い込む必要があるか**の2点で決まる。

| 記号 | 値 | 実装 | 電流（搬送波 / ピーク） | 理由 |
|---|---|---|---|---|
| L1 / L2 / L3 | 47 nH | チップ<br>B82498F3470J000 | 8 mA | SRF 650MHz / 500mA / 0.13Ω、セラミックコア。145MHz で 45Ω |
| L4 | 2.2 µH | チップ<br>B82498F1222J000 | 40 mA（直流） | SRF 330MHz / 130mA / 1.6Ω、フェライトコア。145MHz で 2.48kΩ、負荷 281Ω の 8.8倍 |
| L9 | 1 µH | チップ<br>B82498F1102J000 | 1 mA | SRF 440MHz / 240mA / 0.55Ω、フェライトコア。145MHz で 1.02kΩ |
| L8 | 0.47 µH | 手巻き | <strong>0.80 / 1.50 A（直流）</strong> | 変調電流がそのまま流れる。この電流と SRF 300MHz 以上を両立するチップ品が存在しない。空芯なら飽和も無い |
| L6 | 120 nH | 手巻き | 45 mA | 電流は小さいが、伸縮で追い込めるほうが早い |
| L7 | 56 nH | 手巻き | 8 mA | 2SC4703 の Zin が推定値。**可変が前提** |
| L14 | 33 nH | 手巻き | 224 mA | データシート実測の Zs から決めた値（ADR-016）。心棒は φ3mm・4T（ADR-018）。**可変が前提** |
| L10 | 14 nH | 手巻き | **0.66 / 1.31 A** | 3.5Ω 側の直列素子なので**基板上で最も電流が大きい**。2012 チップ（Q=50）だとピークで 0.44W を消費し、定格も超える。空芯なら 0.12W |
| L11 / L12 / L13 | 71 / 78 / 71 nH | 手巻き | 0.17 / 0.35 A | 挿入損失が `0.22dB（Q=180）→ 0.65dB（Q=60）` に増え、1.5W のうち 200mW を失う |

チップは 5個で、<strong>TDK SIMID 0805-F（B82498F）</strong>で全部そろう。シリーズ名の 0805 はインチ表記で、実寸は 2012（2.0 × 1.25mm）。型番4桁目が `1` ならフェライトコア、`3` ならセラミックコア（低い値ほどセラミック）。

出力 LPF をチップにする選択肢もあるが、代償は挿入損失 0.4dB で、**試作の実測では阻止域を決めていたのはコイル間の結合ではなかった**（[回路設計書 08章](01-circuit-design.md#08-出力-lpf-の設計)）。空芯のままでよい。**L10 は電流の点で空芯以外の選択肢がない**。

> [!WARNING]
> **チョークに磁気シールド品は要らない**
>
> - B82498F は非シールドのドラムコアだが、**L4 / L9 が扱う RF 電流は 1〜3mA しかない**ので、外へ漏らす磁束は問題にならない。
> - 逆に拾う側も心配ない。最も電流の大きい L10（ピーク 1.31A）が L9 に `k = 0.01` という密結合をしたとしても、ゲート節点に現れるのは 1.4mV で、ドライブ 2.7V に対して <strong>−66dB</strong>。終段の利得 12dB を足してもループ利得 −54dB で、発振には遠く及ばない。
> - シールド品は磁性体でモールドする構造なので、**SRF と Q が下がる**。チョークにとって一番大事なのが SRF なので、この用途では不利な取り引きになる。B82498F の SRF 440MHz は非シールドだから得られている。
> - シールドが意味を持ちうるのは**出力 LPF をチップ化する場合**だけ。チップにするならシールド品を選ぶ。

### 巻き方

1. <strong>必ず密着巻きしてから伸ばす。</strong>伸ばすとインダクタンスは減る一方なので、目標より大きい状態から近づける。表の「密着巻き時」が出発点。
2. <strong>心棒から抜くと直径が 0.2〜0.4mm 広がる。</strong>インダクタンスが数% 増えるので、抜いた状態で実測して巻き長を詰める。
3. <strong>両端に 10mm のリードを残す。</strong>被覆はライターで焼いてから磨くか、はんだ槽に浸ける。
4. <strong>固定コイル（L8、L11〜L13）は形を接着で固める。</strong>可変の4本（L6 / L7 / L10 / L14）は追い込みが終わってから固定する。

### 実装上の制約

- <strong>出力 LPF の L11 / L12 / L13 はパッドの並びどおりに実装する。</strong>L12 の footprint だけ 90° 回してあるのは隣と軸を直交させるための意図的なもので、見た目を揃えて同じ向きにしない。間隔は直径の2倍以上。なお試作ではコイルを基板に垂直に立てる実験もしたが 433MHz の減衰はほぼ変わらず、コイル間の結合は支配的な要因ではなかった（[回路設計書 08章](01-circuit-design.md#08-出力-lpf-の設計)・ADR-022）。
- <strong>L8 は LPF から離す。</strong>直径が一番大きいコイルなので、軸を LPF と直交させ、できれば基板の反対側へ寄せる。
- <strong>L8 の直流特性。</strong>DCR 12.9mΩ でピーク 1.5A でも 19mV しか落ちない。空芯なので飽和は原理的に存在しない。自己共振は約 482MHz で 145MHz から十分離れており、実効インピーダンスは 471Ω。負荷 3.5Ω に対して 134倍あり、影響は 0.7%。
- <strong>測定は VHF で。</strong>LC メーターは 100kHz 前後で測るので VHF での実効値とずれる。NanoVNA があれば既知のコンデンサと直列共振させて求めるのが確実。
