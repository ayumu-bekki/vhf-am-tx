## 01 切り離し点と部品を載せる順番

v0.1 基板（1枚・2層。部品は裏面、表面は GND ベタ）での立ち上げと調整。**部品を段階的に載せ、段ごとに切り分けて進める。順序を飛ばさないこと** — 変調器が暴れた状態で終段に給電すると一発で飛ぶ。

### 切り離し点と測定点

基板上のジャンパと 0Ω を外すと、各段を単体にできる。0Ω を外したパッドには NanoVNA のピグテールを当て、網線は隣の GND テストポイントに落とす。

| 記号 | 種類 | 役割 |
|---|---|---|
| J12 | ジャンパ | BP5293-33 → +3.3VA（XIAO の 3V3）。**USB で書き込むときは外す**。BP5293-33 側の電圧は TP6 |
| J11 | ジャンパ | +8V → ドライバのコレクタ給電。外すとドライバだけ止まる。**電流計を挟めばドライバの電流**が読める |
| J13 | ジャンパ | 変調器出力（Mod）→ 終段のドレイン（L8）。外すと終段に給電されない。**電流計（10A レンジ）を挟めばドレイン電流**が読める（最大 1.5A） |
| R28 / TP4 | 0Ω / GND | 搬送波のフィルタ → ドライバ入力の切り離し |
| R37 / TP8 | 0Ω / GND | ドライバ出力 → 終段入力の切り離し |
| R36 / TP7 | 0Ω / GND | 終段の出力整合 → LPF の切り離し。**外したまま送信しない** |
| TP2 | テストポイント | <strong>Mod（変調器出力 ＝ 終段のドレイン電圧）</strong>。校正・変調・発振の確認はここで見る |
| TP3 / TP6 / TP9 | テストポイント | +8V / BP5293-33 出力（3.3V(A)）/ +3.3VB |
| TP5 | テストポイント | 終段のゲートバイアス（RV1） |
| TP1 | GND | 電源側の GND（テスタの黒） |
| J14 | RF 出力 | RG-174 直付け。調整中は先にダミーロード（＋検波プローブ） |

+17.4V にはテストポイントが無い。C19 の + 側（または J8 の 8番ピン）で測る。

## 02 測定器と測り方

### 検波プローブ

RF 電力計は使わず、これで代用する。ダミーロードの両端に当てて、**包絡線の観測と出力電力の測定を1つで済ませる**。145MHz を直接オシロで見る必要がなくなるので、20MHz 帯域のオシロで足りる。

![50Ωダミーロードの両端に1SS270Aダイオードを直結して整流し、100pFと100kΩで平滑する検波プローブの回路図](img/bringup-fig01.svg)

**図 1**　**ダイオードはダミーロードに直結する。間に直流阻止のコンデンサを入れてはいけない** — 100kΩ が引く直流がダミーロードの 50Ω を通って戻ってくるのが前提で、コンデンサがあると帰り道が無くなり、出力は 0V のまま動かない。出力は C50 で直流を切ってあるが、**使う前に J14 の芯線が 0V であることをテスタで確認**する。時定数 `100kΩ × 100pF = 10µs`。145MHz（6.9ns）は完全に平滑され、700Hz（1.43ms）の包絡線は素通しになる。この2桁ずつの余裕が要点。ダイオードには **逆耐圧が必要** — 出力側が +Vpk に充電された状態で入力が −Vpk に振れるので、`2 × 24.5V = 49V` がかかる。1SS106 や BAT43（ともに 30V）では足りない。**1SS270A は DC 60V / ピーク 70V** で余裕がある。100kΩ が引く電流は 6W 時で 0.24mA、ダミーロードから見て 0.4% なので測定対象を乱さない。

### 検波プローブの読み方

出力は「ピーク電圧 − ダイオードの順方向電圧」。1SS270A の Vf はデータシートでは 0.8V だが、それは 100mA での値。**検波電流 0.12mA での実効値は約 0.5V** なので、これを差し引く。

`P [W] = (Vdet + 0.5)² / 100`

| 出力 | ダミーロード両端 | 検波出力 | Vf 補正しない場合の誤差 |
|---|---|---|---|
| 20 mW | 1.41 Vpk | 0.91 V | −58%（使えない） |
| 100 mW | 3.16 Vpk | 2.66 V | −29% |
| 500 mW | 7.07 Vpk | 6.57 V | −14% |
| **1.5 W** | **12.25 Vpk** | **11.75 V** | −8% |
| 6 W（変調ピーク） | 24.49 Vpk | 23.99 V | −4% |

**1V を下回る領域では二乗検波になって使えない**。搬送波そのもの（+4.7dBm = 0.54Vpk）は測れないので、そこはオシロで波形を確認するだけにして、レベルの判定はドライバの出力（R37 のパッド、+20dBm）から行う。

> [!WARNING]
> **絶対値だけは較正する**
>
> - 1SS270A はシリコンの高速スイッチング品で、**逆回復時間 3.5ns が 145MHz の半周期 3.45ns と同程度**。逆回復のあいだ電荷が入力側へ戻るため、**読みが低めに出る**。その量はデータシートから予測できない。
> - **包絡線の形、変調度、整合のピーク探しは相対測定**なので、これは問題にならない。1SS270A 単独で足りる。
> - 絶対電力だけは補正係数が要る。<strong>1.5W 無変調なら逆電圧は 24.5V なので、30V のショットキ（1SS106 など）が安全に使える。</strong>ダイオードを差し替えて同じ搬送波を読み比べれば、そのまま補正係数になる。ショットキ側は Vf 0.3V・逆回復ゼロなので、こちらを基準にする。
> - 変調をかけた 6W ピークでは逆電圧が 49V になるので、**ショットキのまま送信しない**。較正が済んだら 1SS270A に戻す。

### NanoVNA でマッチングを追い込む

NanoVNA があれば、出力側の整合は**能動素子を載せる前に**片付けられる。入力側は素子を載せてから測るが、終段（C級）だけは小信号で追い込めないので大信号で決める。測る場所・目標・触る素子は[手順 6](#手順-6--ドライバj11-は開けたまま始める)・7 に、試作で決まった値は 04章にまとめた。

> [!WARNING]
> **NanoVNA を壊さないために**
>
> - <strong>送信状態で NanoVNA を繋がない。</strong>CH1 の耐入力は +10dBm 前後。ドライバ出力（+20dBm）でも終段出力（+31.8dBm）でも一撃で壊れる。
> - 測定前に必ず **CLK0 を停止するか、搬送波側の同軸を抜く**。
> - 増幅段を通して S21（利得）を測るときは、**CH1 の手前に 20dB の減衰器**を入れる。NanoVNA の出力 −10dBm に 22dB の利得が乗ると +12dBm になり、上限を超える。減衰器を付けた状態で THRU 校正を取れば、読みがそのまま利得になる。

> [!WARNING]
> **操作の基本（試作で実際につまずいた点）**
>
> - <strong>掃引範囲を決めてから校正する。</strong>校正は範囲に紐づくので、範囲を変えたら取り直す。整合の追い込みは <strong>100〜200MHz / 101点（1MHz/点）</strong>、LPF と発振チェックは 100MHz〜1GHz。2GHz まで広げると 1点 18.6MHz になり 145MHz 付近が解像できない。
> - <strong>校正の基準面はケーブルの先端。</strong>OPEN / SHORT / LOAD はケーブルの先に付けて取る。校正していないケーブルの先を測ると、長さに応じた大きなリアクタンスが見えるだけで何も分からない。
> - <strong>S21 は THRU（と ISOLN）まで取る。</strong>THRU を飛ばすとケーブル2本の損失（145MHz で合計 0.3dB 前後）がそのまま挿入損失に乗る。
> - <strong>マーカーは周波数を手で入力して置く。</strong>最小値サーチを使うと寄生共振の谷の底に乗り、実力より良く見える。
> - <strong>深さは LOGMAG（dB）で、インピーダンスはスミスチャートで読む。</strong>SWR 表示はスケールを誤ると読めない。スミスの R + jX から `|Γ| = |Z − 50| / |Z + 50|`、`RL = −20·log|Γ|` で dB を検算できる。
> - <strong>発振チェックは S11 の LOGMAG で 0dB を超える点を探す。</strong>受動回路なら S11 は必ず 0dB 以下。+1dB 以上の鋭いピークがあれば負性抵抗＝発振。0.5dB 以内のなだらかな超過は校正誤差。

### ① 素子を載せる前 — 抵抗置換法（S11）

整合回路が「計算どおりのインピーダンス変換をしているか」を、能動素子抜きで確認する。**Q3 と Q4 を実装する前に**やる。ドライバはコレクタパッドに **270Ω**、終段はドレインパッドに **3.3Ω** を仮付けし、出力側から S11（反射）を見て 145MHz で <strong>−20dB 以下</strong>に追い込む。

この2つは**ロードラインで決まる実数の抵抗値**への変換なので、抵抗で置き換えても本番とほぼ等価になる。仮付けする抵抗は **1% 品・リード最短**にする。ここの抵抗値がそのまま測定の基準になる。

> [!WARNING]
> **どのツマミが何を動かすか — ドライバと終段で逆になる**
>
> - **ドライバ**は「負荷 270Ω に並列 C、その先に直列 L6、測定ポート」の順。並列 C が負荷に直接乗っているので、**並列 C（C39 または浮遊容量）が実部を決め、L6 は整合する周波数（虚部）だけを動かす**。L6 を伸ばすと谷が上の周波数へ、縮めると下へ動く。
> - **終段**は「負荷 3.3Ω に直列 L10、その先に並列 C53、測定ポート」の順で、役割が入れ替わる。<strong>L10 がスミスチャート上の「どの定コンダクタンス円に乗るか」（実部）を決め、C53 はその円に沿って動かす（虚部）</strong>。C53 をどれだけ回しても中心に来ないときは、円が中心を通っていないので L10 を直す。
> - どちらも**実部を決める素子を先に、虚部だけを動かす素子を後に**合わせると1往復で収束する。逆順にすると行ったり来たりになる。

> [!WARNING]
> **抵抗置換法の落とし穴（試作で判明）**
>
> - <strong>並列 C には浮遊容量が乗る。</strong>ドライバは必要な並列 C が 8.5pF しかないのに、コレクタ節点の浮遊が 6.63pF あった。トリマが最小端に張り付いたら、トリマを外して 145MHz の実部 R を読み、`C = √(R_L/R − 1) / (ω·R_L)`（R_L は仮付けした抵抗）で浮遊を逆算してから部品を決める。
> - <strong>素子を載せると容量が増える。</strong>ドライバは Cob（約 1.5pF）が並列 C に加わる。**Cob と同じ値の C0G を空いたパッドに仮付けして合わせる**と、Q3 を載せたあとの状態を再現できる。終段の Coss はドレイン側（低インピーダンス側）に付くので影響は小さく、L10 は 14nH 前後に収まるが、必要な並列 C は 83pF → 86pF 程度動く見込み。**終段は −20dB を少し超えたら深追いしない**。
> - <strong>追い込んだら必ず抵抗を外す。</strong>終段の 3.3Ω を付けたまま Q4 を載せて給電すると、`3.6V ÷ 3.3Ω = 1.1A` が流れ続ける。外したらテスタでドレインパッド〜GND が数百Ω以上あることを確認する。

### ② 素子を載せてから — 入力側の S11

入力インピーダンスはバイアス状態で変わるので、**電源を入れ、バイアスを規定値にした状態**で測る。出力側は必ず 50Ω で終端する（ドライバなら R37 のパッドにピグテール＋50Ω、終段なら J14 にダミーロード）。NanoVNA の出力は −13dBm 程度なので、素子はほとんど動かない。

- <strong>ドライバ（Ic 35mA）</strong>は小信号でも導通しているので、S11 で当たりがつく。目標 <strong>−10dB 以下</strong>、触る素子は L7 → C41。
- <strong>終段（C級・Idq ≈ 0）</strong>は小信号ではゲートが全く導通せず、S11 は 0dB 付近に張り付く（[回路設計書 07章](01-circuit-design.md#07-終段の整合回路)）。**ここでは整合の目標を置かず、発振していないことの確認にだけ使う**。L14 / C61 は大信号で決める。

> [!WARNING]
> **小信号 S11 の限界**
>
> - C級動作では**入力インピーダンスがドライブレベルで変わる**。NanoVNA の −13dBm と、実際の +20dBm では Ciss の実効値もゲートの実部も違う。
> - したがって入力側の追い込みは、最終的には大信号を入れて<strong>「同じ出力を得るのに必要なドライブが最小になる点」</strong>を探して決める。
> - 逆に言えば、**出力側（抵抗置換法）は大信号でもほぼそのまま通用する**。ロードラインで決まる実数負荷への変換だから。

### ③ フィルタの通過特性 — S21

①②が「1つのポートに入れて跳ね返ってくる量」を見る**反射**の測定（S11）なのに対し、出力 LPF の検証だけは**通過**の測定（S21）を使う。NanoVNA の CH0 をフィルタの入口、CH1 を出口に繋ぎ、**入れた信号のうちどれだけ通り抜けたか**を見る。

「掃引」は、周波数を1点ずつ変えながら順に測っていく動作のこと。横軸が周波数・縦軸が dB のグラフが描かれるので、**通過域（145MHz）がほぼ 0dB で平ら、そこから上で急降下し、阻止域（288MHz / 432MHz）で深く落ちている**という形になっていれば正常。7次チェビシェフは阻止域に谷を持たない設計なので、**実測に現れる谷と山はすべて寄生の共振**。谷が浅いときの切り分けは[手順 7](#手順-7--終段と-lpfj13-は開けたまま始める) に書いた。

### 測っていない側のポートの扱い

- <strong>Q3 / Q4 を載せる前の抵抗置換測定は、反対側は開放でよい。</strong>整合回路の先は素子の未実装パッドで途切れていて、信号が伝わる経路が無い。
- <strong>素子を載せてバイアスを与えた後の入力側 S11 は、出力側を必ず 50Ω で終端する。</strong>内部帰還（Cbc / Crss）を介して出力側の状態が入力インピーダンスに影響し、開放だと発振もしやすい。

### 調整できる要素の一覧

| 要素 | 何を決めるか | いつ決めるか |
|---|---|---|
| L6 | ドライバの出力整合（C39 は実装しない） | 抵抗置換法（Q3 実装前） |
| L7 / C41 | ドライバの入力整合＝利得 | 小信号 S11 で当たり、大信号で確認 |
| L10 / C53 | 終段の出力整合＝**出力電力そのもの** | 抵抗置換法（Q4 実装前）→ 大信号で出力最大点へ |
| RV1 | 終段のゲートバイアス（Idq、TP5 で読む） | Q4 実装直後。温まってから再確認 |
| L14 / C61 | 終段の入力整合＝利得 | **大信号のみ**（小信号 S11 は使えない） |
| `kModKCal` | 搬送波レベル（TP2 = 3.6V） | [手順 8](#手順-8--校正と変調)。変調度とは独立 |
| `kXGainA2a` | 変調度 80% | [手順 8](#手順-8--校正と変調)。搬送波レベルとは独立 |

整合は **出力側を先に決めてから入力側**。出力側が電力を決め、入力側が利得を決める。終段は相互作用があるので、大信号で 2〜3 往復させる。

## 03 立ち上げ手順

部品を段階的に載せ、段ごとに切り分けて進める（01章）。**順序を飛ばさないこと** — 変調器が暴れた状態で終段に給電すると一発で飛ぶ。

### 手順 1 — 通電前（電源部を載せたところ）

- <strong>各レールと GND の間に短絡が無いこと。</strong>テスタの黒を TP1 に当て、+BATT（C4 の + 側）、+8V（TP3）、3.3V(A)（TP6）、+3.3VB（TP9）、+17.4V（C19）を当たる。コンデンサの充電で値は上がっていくが、数Ωで止まるようなら実装ミス。
- <strong>向きの確認。</strong>Q1（D=電池側 / S=負荷側）、電解コンデンサ（C4・C32・C48）の極性、D1。
- <strong>U4 の裏の露出パッドがはんだ付けされていること。</strong>GND 兼放熱。表面のサーマルビアからはんだが見えれば付いている。

### 手順 2 — 電源

電流制限つき電源（200mA 程度に制限）で J5 に 12.8V を与え、J4（SW_Power）を入れる。この段階の消費は 50mA 以下のはず。J12 はまだ開けておく。

| 測る場所 | 目標 | 確認内容 |
|---|---|---|
| TP3（+8V） | 7.98 V ±2% | R25 / R27 の分圧 |
| TP6（3.3V(A)） | 3.20 〜 3.40 V | BP5293-33 単体の出力（±3%）。確認したら J12 を閉じる |
| TP9（+3.3VB） | 3.3 V ±4% | Si5351A の VDD。3.5V を超えていないこと |
| C19（+17.4V） | 17.4 V ±5% | R17 を 100k＋27k にした場合は 17.0V 前後。電池を 10.5V まで下げても保たれること |

### 手順 3 — MCU と表示

- <strong>書き込みは J12 を外して USB で。</strong>書き込みが済んだら USB を抜き、J12 を閉じてから電源で動かす（ADR-014）。
- I2C で Si5351A（0x60）と LCD（0x3E）が応答すること。LCD に文字が出ること。ここで CLK0 はまだ有効にしない。
- <strong>起動ログの `carrier` / `hard_max` を確認する。</strong>`kModKCal = 0.3295`（試作の値）なら carrier 84 / hard_max 181。ベンチ用の定数のまま書き込んでいないこと。
- 押しボタン（SW1〜SW3）でモードとテストモード（T:DUTY / T:CARR / T:TONE）が切り替わること。

### 手順 4 — 変調器単体（J13 は開けたまま）

変調器の出力を終段に繋がず、TP2 で単体の動作を確かめる。RF 段はまだ載っていない。<strong>ここを飛ばして終段に繋がないこと。</strong>

> [!WARNING]
> **R8 とファームウェアの定数は対で変える**
>
> - R8 は 22kΩ（ゲイン 3.2）。ファームウェアの定数はこのゲインで計算してある（`kModKCal = 0.3295` で**搬送波 84 / 絶対上限 181**。ADR-024、ファームウェア仕様書 §6・§11）。
> - 定数が R8 と合っていないと（例：ゲイン 3.0 用の 93 / 200）、搬送波が 3.84V、上限が 8.25V 相当の指令になる。上限側は 8V レールに張り付き、終段の損失が約 6.3W（[回路設計書 03章](01-circuit-design.md#03-変調器m3の回路図)）に達する。下の表の T:DUTY 上限で 7.75V を超えないことで確かめる。

1. <strong>TP2 と近くの GND（J6 の 3番ピンなど）の間に 1kΩ（1/4W）のダミー負荷を付ける。</strong>ソースフォロワは電流を吸い込めないので、出力を下げるときは負荷が放電を受け持つ。無負荷だと出力の C8（0.1µF）を帰還抵抗 R5＋R8（32kΩ）でしか放電できず、700Hz の下り坂に追従できない。**波形は「速く上がって直線的に下がる」のこぎり波になる**（変調器の不良ではない）。追従には 2.8kΩ 以下の負荷が要るので、余裕を見て 1kΩ（損失 最大 42mW）。直流の確認だけなら無負荷でもよい。
2. **電源投入・リセットで TP2 が 0V のままか**をオシロのシングルトリガで確認する。PWM は GPIO2（D2）で、リセット直後の内部プルの状態がデータシートで確認できていない（[回路設計書 04章](01-circuit-design.md#04-m2-トーン生成と平滑フィルタ)）。0V から浮くなら R23（100kΩ のプルダウン）を小さくする。
3. <strong>直流の確認（T:DUTY）。</strong>

   | 指令（T:DUTY） | TP2 の期待値 | 試作の値 |
   |---|---|---|
   | 0 | 0 V | 0.11 V |
   | 84（搬送波） | 3.6 V ±0.1V で静止 | 3.58 V |
   | 上限（181） | 7.75 V 以下で止まる | 7.55 V |

   1カウント約 0.041V で直線になっていること。8V に張り付いたら定数がゲイン 3.2 用になっていない。

4. <strong>交流の確認（T:TONE）。</strong>TP2 に 0.7〜6.5V の 700Hz 正弦波。頭や谷が潰れていたら、オペアンプの振れ幅か 8V レール（TP3）の落ち込みを疑う。RF 側まで戻らず、ここで直す。
5. <strong>発振していないこと。</strong>T:DUTY 84 で TP2 を AC 結合にし、**1µs/div と 10〜20ns/div** の両方で見る。2SK4017 をリード線で引き出しているので、速い時間軸の寄生発振も確かめる。2SK4017 が負荷の割に温かければ発振を疑う。

### 手順 5 — 搬送波

搬送波のフィルタとパッドを載せる。R28 はまだ載せない。**R28 の Si5351A 側のパッドにピグテールを当て**（網線は TP4）、50Ω で終端してオシロで見る。

- 周波数が設定どおりか（MultiSynth 偶数整数 ÷6、PLL 小数分周 — [回路設計書 05章](01-circuit-design.md#05-キャリア整形フィルタとパッド)）。
- レベル <strong>+4.7dBm（50Ω で 1.1Vpp）</strong>前後。パッドを 3dB から振れば調整できる。
- 波形が正弦波に近いこと。方形波のままなら定数k LPF が効いていない。

### 手順 6 — ドライバ（J11 は開けたまま始める）

1. <strong>Q3 を載せる前に出力側を追い込む（抵抗置換法）。</strong>Q3 以外を載せ、**C39 のパッドに 270Ω（1608・1%）を載せ、その上に Cob の代役の 1.5pF C0G を重ねて付ける**（C39 は本来は実装しない。[回路設計書 06章](01-circuit-design.md#06-ドライバ段2sc4703)）。R37 は載せず、**R37 のドライバ側のパッド（C37 側）に NanoVNA の CH0** を当てる（網線は TP8）。100〜200MHz で校正して S11 を見る。<br>谷が 145MHz より低ければ L6 を伸ばし、高ければ縮める。**谷が 145MHz に来ても底が浅いときは並列 C の過不足**で、L6 では直らない（上の「落とし穴」）。この基板は Q3 の放熱のためにコレクタに小さなベタがあり、浮遊容量が試作より 0.5〜0.8pF 多い。145MHz で −20dB 以下が目標。届いたら **270Ω と 1.5pF を外す**。
2. **Q3 を載せ、J11 に電流計を挟んで +8V を与える**（ドライブはまだ入れない）。**37mA 前後**（Ie 35mA + バイアス分圧 2.2mA）。電流計が怪しいときは Q3 のエミッタ電圧 ÷ 12Ω で Ie を読む（試作：0.415V = 34.6mA）。
3. <strong>入力側の S11 を測る。</strong>R28 は載せないまま、**R28 のドライバ側のパッド（C40 側）に CH0**（網線は TP4）。<strong>出力側は R37 のドライバ側のパッドにピグテール＋50Ω で終端する。</strong>目標 −10dB 以下。触るのは L7 → C41。大信号では Zin が変わるので、当たりをつける工程として深追いしない。
4. <strong>大信号で確認する。</strong>R28 を載せる。出力は R37 のドライバ側のパッドからピグテールでダミーロード＋検波プローブへ。CLK0 を有効にして、目標 <strong>+20dBm（100mW）＝検波 2.66V 以上</strong>（試作は Si5351A の CLK0 駆動を最小の 2mA にして約 190mW・検波 3.90V）。**J11 の電流がほとんど増えないのが正常**（エミッタ抵抗で平均電流が固定される）。入力を増やしても出力が増えないときは、整合ではなく電流の天井を疑う — 取り出せる電力は概ね `Ie² × 281Ω ÷ 2` で頭打ち。
5. <strong>発振チェック。</strong>CLK0 を止めても出力に何も出ないこと。怪しければ R29 を 10Ω → 22Ω に増やす。

ここまででドライバが完成。電流計を外して J11 を閉じる。

### 手順 7 — 終段と LPF（J13 は開けたまま始める）

1. <strong>LPF 単体を先に検証する（R36 を外したまま）。</strong>NanoVNA の <strong>CH0 を R36 の LPF 側のパッド（C54 側）</strong>（網線は TP7）、**CH1 を J14 の RG-174 の先**に繋ぐ。100MHz〜1GHz で SOLT・ISOLN・**THRU** まで校正し、S21 を LOGMAG で見る。マーカーは 145 / 288 / 432MHz に手で置き、288MHz は 284〜292MHz の中の最悪値を読む。同じ接続で S11 も見て、145MHz のリターンロスを確認する。<br>目標は 145MHz で <strong>−0.3dB 以内・リターンロス 20dB 以上</strong>、288MHz で <strong>−50dB 以下</strong>。432MHz は計算上 −78dB だが、試作では −41dB で頭打ちになった（ADR-022）。この基板はシャント C の GND をビアで最短に落としてあるので、どこまで改善したかを記録する。<br>阻止域が浅いときの切り分け：① CH0 のピグテールを基板から浮かせた値が測定系の床（試作：433MHz で −65dB）。② L12 の片脚を浮かせた値がフィルタを通らない経路の床（試作：−56dB）。③ 実測がこの2つより十分浅ければ、漏れはフィルタの素子（シャント C の GND 帰路）を通っている。
2. <strong>Q4 を載せる前に出力側を追い込む（抵抗置換法）。</strong>Q4 以外を載せ、<strong>Q4 のドレインパッドとタブ（GND）の間に 3.3Ω（1%）</strong>をリード最短で仮付けする。R36 は外したまま、<strong>CH0 を R36 の整合側のパッド（C50 側）</strong>（網線は TP7）に当て、100〜200MHz で S11 を見る。<br>L10 → C53 の順に合わせる（L10 が実部、C53 が虚部）。目標 −20dB 以下。**C53 の位置を記録する** — 最大端に張り付いたら C52 を大きく、最小端なら小さくする（試作は 47pF → 56pF に変更）。−20dB を少し超えたら深追いしない（Q4 の Coss で最適点が少し動く）。<br>最後に 3.3Ω を外し、ドレインパッド〜GND が数百Ω以上あることをテスタで確認する。
3. <strong>RV1 の素性を確かめる。</strong>RV1 を 0V 側いっぱいにして、TP5 の電圧を見ながら全域回す。<strong>0V 〜 3.20V（±5%）</strong>で滑らかに動くこと、どちら向きが「上げる」かを記録する（25回転）。確認したら 0V 側へ戻す。
4. <strong>Q4 と R36 を載せ、J14 にダミーロード＋検波プローブを繋ぐ。</strong>T:DUTY 0 にしてから **J13 に電流計（10A レンジ）を挟む**。T:DUTY 84 で TP2 が 3.6V になり、ドレイン電流がほぼ 0 であること。
5. <strong>ゲートバイアスを決める。</strong>RV1 をゆっくり上げ、ドレイン電流が 1mA 流れ始めたときの TP5 の電圧を Vgs(th) として記録する（1.5〜2.5V のどこか。試作の個体は 1.612V）。そこから 0.3〜0.5V 戻し、Idq が 0〜10mA に収まることを確認する（試作は 1.30V）。RV1 の回転位置ではなく TP5 の電圧を記録する。Vgs(th) は約 −4mV/℃ で動くので、浅く戻した場合は[手順 9](#手順-9--スプリアスと連続運転) で温まってから測り直す。
6. <strong>入力側 S11 で発振していないことを確かめる。</strong>R37 は載せないまま、<strong>CH0 を R37 の終段側のパッド（C60 側）</strong>（網線は TP8）に当てる。バイアスは規定値、T:DUTY 84（TP2 3.6V）、J14 はダミーロード。100MHz〜1GHz の S11 で 0dB を超える点が無いこと。整合はここでは追い込まない — C級のゲートは小信号で導通しないので、S11 は 0dB 付近に張り付くのが正常（[回路設計書 07章](01-circuit-design.md#07-終段の整合回路)）。
7. <strong>大信号で整合する。</strong>R37 を載せる。**電源の電流制限を 1.5A に上げる**（1.0A だと変調の山で CC に入り、出力を削る）。**T:CARR L（搬送波の半分の電圧）から始めて**、L10 を伸縮して出力最大点、次に C53。続けて L14 を伸縮して利得最大点、次に C61。2〜3 往復させる。<br>T:CARR H で **検波 11.75V（1.5W）、J13 のドレイン電流 0.6〜0.7A、TP2 3.6V** 前後を確認する（試作は TP2 3.57V・検波 11.36V ≒ 1.41W）。校正前なので TP2 が少しずれていてもよい。
8. <strong>発振チェック。</strong>CLK0 を止め、TP2 3.6V のまま、J14 に何も出ないこと（SDR）。バイアスを振ったとき、ドライブの有無を切り替えたときも同様。

確認が済んだら電流計を外し、J13 を閉じる。

### 手順 8 — 校正と変調

1. <strong>RF の飛び込みが無いことを確かめる。</strong>同じ指令で T:DUTY 84（RF なし）と T:CARR H（RF あり）の TP2 を比べる。帰還は TP2 の近くから取っているので、**正常なら差は 0.05V 以内**。大きくずれる（試作のブレッドボードでは 3.6V → 1.2V）なら、オペアンプのピン直近のパスコン（C2 / C3 / C25）と C66 / C67、2SK4017 への4本の線の取り回しを見直す。
2. <strong>搬送波を校正する。</strong>T:CARR H で TP2 を測り、`kModKCal = 今の値 × 3.6 ÷ 実測` で書き直す。書き込み後、TP2 が 3.6V ±0.05V になること、起動ログの carrier / hard_max が変わったことを確認する（ファームウェア仕様書 §11）。
3. <strong>変調度を合わせる（T:TONE）。</strong>検波プローブの出力をオシロで見て、山と谷を読む。`m = (山 − 谷) ÷ (山 + 谷)`（山・谷それぞれに 0.5V を足して計算）。<strong>80% ±5%</strong> に `kXGainA2a` で合わせる（試作：山 19.2V / 谷 1.4V で約 82%）。

   - 谷が沈みきらない → RV1 で Idq を下げる方向へ。それでも駄目ならドライブを絞る（パッドを増やす）。負変調は 70〜85% で頭打ちになりやすい（ADR-017）。
   - 山が潰れる → 変調の山で TP3（+8V）が 7.4V を割っていないか、電源の電流制限に当たっていないか。

4. <strong>山の圧縮を確かめる。</strong>T:CARR H と P（搬送波 × 1.8、3秒で自動停止）の検波電圧から出力を出し、ドレイン電圧の2乗の比と比べる。試作は −0.47dB で受け入れた。

### 手順 9 — スプリアスと連続運転

- <strong>高調波。</strong>290MHz と 435MHz が −60dBc 以下。3倍波は終段自身の3倍波と LPF の 432MHz の実測（[手順 7](#手順-7--終段と-lpfj13-は開けたまま始める)）で決まる。割ったら出力に外付けの同軸 LPF を1段足す（ADR-022）。
- <strong>近傍のスプリアス（SDR）。</strong>±250kHz（PWM 残留）、±24.3kHz（デューティ更新レートの折返し）、±340kHz / ±570kHz 前後（降圧 DC-DC ×2）、±300kHz（チャージポンプ）。LCD の書き換え（I2C）のたびに音やスプリアスが出ないかも聞く。
- <strong>占有周波数帯幅。</strong>A2A なら ±3kHz 以内に収まること。トーンが正弦波でないと奇数次側波帯が延々と出る。
- <strong>キーイング。</strong>立ち上がり・立ち下がりを 5ms 程度なまらせ、クリックが出ないこと（[回路設計書 04章](01-circuit-design.md#04-m2-トーン生成と平滑フィルタ)）。
- <strong>ケースに入れて確認する。</strong>フタの開け閉めで搬送波レベル（TP2・検波電圧）が変わらないこと。
- <strong>連続 30分。</strong>2SK4017 のヒートシンクの根元（素子の真裏）が **60°C 以下**で飽和すること（[製作ガイド 03章](02-build-guide.md#03-2sk4017-の取り付けとケース)）。Q4 と U4 の温度も記録する。上がり続けるなら放熱不足。
- <strong>温まってから Idq を再確認。</strong>CLK0 を止めて T:DUTY 84、J13 に電流計。冷間で合わせた値からずれていれば RV1 を合わせ直す。

> - <strong>抵抗置換用の 270Ω / 3.3Ω を付けたまま素子を載せて給電しない。</strong>終段は 1.1A が流れ続ける。
> - <strong>J13 に挟む電流計は 10A レンジで。</strong>mA レンジのまま搬送波を出すとヒューズが飛ぶ。
> - <strong>USB で書き込むときは J12 を外す。</strong>内蔵レギュレータと BP5293-33 がぶつかる。
> - <strong>[手順 4](#手順-4--変調器単体j13-は開けたまま)（変調器単体）を飛ばさない。</strong>変調器が暴れた状態で終段に給電すると一発で飛ぶ。

### 試作から分かったこと

- <strong>検波プローブに直流阻止の C を入れてはいけない。</strong>R1 の直流の帰り道が無くなり、出力が 0V のまま動かない（02章の図は修正済み）。
- <strong>エミッタ抵抗でバイアスしたドライバは、ドライブで平均電流が増えない。</strong>出力の上限は Ie で決まる。入力を増やしても出力が増えないときは、整合より先に電流を疑う（ADR-025）。
- <strong>抵抗置換法は浮遊容量の実測を兼ねる。</strong>整合が合わないとき、並列 C を外して実部を読めば、パターン側に何 pF 乗っているかが分かる。必要な並列 C が小さい整合は、浮遊で大半が埋まる。
- <strong>素子を載せたあとに加わる容量は、代役の固定 C で先に再現できる。</strong>Cob 1.5pF の代役を仮付けして合わせた結果、予測 54.0 − j0Ω に対して実測 53.4 − j2.2Ω と 1% の精度で合った。
- <strong>ドライバと終段で、整合のツマミの役割が逆になる。</strong>並列 C が負荷側にあるか測定ポート側にあるかで決まる（02章）。
- <strong>C級の終段入力は小信号で測れない。</strong>データシートの Zs は AB級（Idq 500mA）の値で、Idq ≈ 0 のゲートは −13dBm では導通しない。
- <strong>LPF の 3倍波の頭打ちはコイル間の結合ではなかった。</strong>コイルの向きを変えても動かず、L12 の片脚を浮かせると 15dB 深くなった。シャント C の GND 帰路が有力（ADR-022）。
- <strong>変調器の位相補償は「オペアンプ出力 ↔ −入力」の C。</strong>帰還抵抗に並列の C では約 1.2MHz で発振し、山の圧縮も −1.35dB に悪化していた（ADR-026）。
- <strong>オペアンプの入力は RF で狂う。</strong>ピン直近のパスコン（V+ に 0.1µF＋1000pF、＋入力に 1000pF）が無いと、搬送波を出しただけで変調器の出力が 3.6V → 1.2V にずれた。
- <strong>大電流の試験の前に、電源の電流制限とオシロのプローブ倍率（本体とメニュー）を確認する。</strong>どちらも測定を誤らせた。
- <strong>NanoVNA の操作で結果が大きく変わる。</strong>掃引範囲ごとの校正、ケーブル先端での校正、マーカーを手で置く、深さは LOGMAG で読む（02章「操作の基本」）。
