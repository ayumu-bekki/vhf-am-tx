# 144MHz 送信機 回路設計書

終段ドレイン変調（高レベル変調）による 1.5W の A2A 送信機の**回路と定数**。各段の回路・定数の根拠・電源・レベル配分・設計上の注意を扱う。部品と基板・組み立ては [製作ガイド](02-build-guide.md)、立ち上げと調整は [調整手順書](03-bring-up.md)、方式選定の経緯は 設計判断記録、MCU の中のこと（ADC・信号処理・PWM・動作モード）はファームウェア仕様書。境界は **MCU のピンから外が本書、内がファームウェア仕様書**。

| Emission | **A2A** | トーン変調電信 |

## 02 なぜこれが AM になるのか

![上段に0Vから7.2Vまで揺れるドレイン電圧の正弦波、下段にそれと同じ形の包絡線を持つ144MHz出力を並べた波形図](img/design-fig02.svg)

**図 2**　変調器は終段の電源そのものを音声波形で揺らす。無変調時 3.6V で 1.5W、ピーク 7.2V で 6W。ピーク時の 6W は変調器が供給しているので、音声側にも約 1.5W のパワーアンプが必要になる — これが「高レベル変調」と呼ばれる理由。

## 03 変調器（M3）の回路図

オペアンプが負帰還で 2SK4017 のソース電圧を MCU の波形に追従させる、単なるリニアレギュレータ。違うのは基準電圧が音声波形で動くことだけ。

![NJW4190M で作った17.4Vで動くNJM2125Fが、2SK4017のソースフォロワを負帰還制御し、8Vレールから3.6V±3.6Vの変調電圧を作って終段ドレインへ供給する回路図](img/design-fig03.svg)

**図 3**　M2 が渡す 700Hz 正弦波（1.125V 中心）を基準として、ソースフォロワの出力を制御する。帰還は出力を 22k/10k で 1/3.2 に分圧して −入力へ（**ゲイン 3.2 倍**）。出力 3.6V のとき帰還ノードは 1.125V になるので、MCU 側は 1.125V を中心に振ればよい。出力側にクランプ用ツェナーは置かない。**ソースフォロワは +8V レールを超えられないので、ドレイン電圧の上限は構造的に 8V に決まっている**（下記）。

### 定数の根拠

| 部品 | 値 | 根拠 |
|---|---|---|
| 基準入力 | M2（1k + 47nF ×2）より | 1.125V を中心に ±0.90V。平滑フィルタの定数は 04 章 |
| 帰還分圧 | 22k / 10k | ゲイン `1 + 22k/10k = 3.2`。出力 0〜7.2V → 帰還ノード 0〜2.25V。MCU の 3.3V PWM でそのまま作れる範囲に収まる。当初の 20k（ゲイン 3）から、**E12 で揃えて部品の種類を減らすため**に変更（ADR-024） |
| 位相補償 | **C6 1000pF**（オペアンプ出力 ↔ −入力） | 直流と低域の帰還は R8 / R5 でソースから、**約 20kHz より上の帰還はオペアンプの出力から直接**取る。ゲート容量と 470Ω の遅れがループの外に出るので安定する。当初の「R8 に並列 470pF」は高域でループ利得を上げてしまい、**約 1.2MHz で発振した**（ADR-026） |
| パスコン | V+ に 0.1µF＋1000pF、＋入力に 1000pF | **オペアンプのピンの直近**に置く。無いと 145MHz が入力段で整流され、搬送波を出しただけで出力が 3.6V → 1.2V にずれた（[調整手順書 04章](03-bring-up.md#04-試作で決まった値調整の出発点)） |
| ゲート抵抗 | 470Ω（R9） | オペアンプ出力とゲート容量を絶縁。これが無いと発振する。**2SK4017 を引き出すので、R9 は FET の足元（J7 側）に置く**（[製作ガイド 03章](02-build-guide.md#03-2sk4017-の取り付けとケース)） |
| 出力コンデンサ | 0.1µF **のみ**（C8） | 大容量は禁止（11章「回路の落とし穴」）。**基板側の Mod / TP2 ノードに置く** — Mod 線は終段（J13）まで基板を横断するので RF を拾いやすく、ここで落とさないと R8 から −入力へ入る |
| ドレインのパスコン | 0.1µF（C5） | **FET の足元（J7 側）で D–GND**。8V の線が長くなるぶん、直近で電源インピーダンスを下げる |
| RFC | 0.47µH 空芯（自作） | 145MHz で 471Ω、700Hz で 0.002Ω。RF を止めて音声を通す。巻き方は [製作ガイド 04章](02-build-guide.md#04-手巻きコイルの製作) |
| Vgs 保護 | 不要 | 電源が 17.4V なので Vgs は最大 17.4V。2SK4017 の Vgss=±20V に収まる |

> [!WARNING]
> **出力クランプ用ツェナーは置かない**
>
> - ソースフォロワの出力は <strong>+8V レールを超えられない</strong>。オペアンプが振り切れても、Q2 が短絡故障しても、ドレイン直流電圧の上限は 8V。設計ピーク 7.2V に対して 11% しか上がらず、**上限はレールがすでに決めている**。
> - ここに 7.5V のツェナーを置くと、レールより 0.5V 低いところでクランプしようとすることになる。2SK4017 の Rds(on) は 0.1Ω 程度なので無負荷時に数 A が流れ込み、どんな定格のツェナーも焼ける。しかも導通するのは「ドライブ無し」＝終段に電流が流れず無害な場面だけで、**危険なときには働かない**。
> - レールより上（9.1V など）に置けば安全だが、その場合に吸うのは L8 のフライバック `½LI² = 0.53µJ` だけ。しかも変調経路は音声帯域なので `di/dt` が小さく、実際に発生するのは `0.47µH × 1.5A/100µs = 7mV` 程度。<strong>働く場面が存在しない。</strong>
> - ドレインが負に振れた場合は LDMOS のボディダイオードが −0.7V でクランプする。外付けは要らない。
>
> では何が保険になるか
>
> - <strong>ファームウェアのデューティ上限。</strong>運用範囲の上端 0.652、どんな場合も超えない絶対上限 0.730（04章）。搬送波レベルも変調度も数値で決まる設計なので、ここで縛るのが筋。
> - <strong>ヒートシンクを「8V 張り付きでも壊れない」寸法にする。</strong>8V 連続では終段の損失が約 6.3W に達する（通常運用は 1W 未満。試作の実測から換算）。**10°C/W 以下**の放熱にしておけば温度上昇 63°C で収まり、故障しても壊れない。通常運用では 10°C 程度しか上がらない。

### 放熱の見積もり

損失は `(8V − ドレイン電圧) × 電流`。終段を 3.57V ÷ 0.65A ≒ 5.5Ω の抵抗とみなすと、**ドレイン 4V（レールの半分）で最大**になり、搬送波はそのすぐ近くにいる。**連続搬送波が最も厳しい条件**で、余裕を見て **3.5W** で設計する。

| 状態 | 2SK4017 | 終段 Q4（参考） |
|---|---|---|
| 搬送波（3.6V） | 約 2.9W | 約 0.7W |
| 変調 82%（平均） | 約 2.1W | 約 0.9W |
| ドレイン 4V（最大点） | 約 2.9W | — |
| 基準が張り付いて 8V | ほぼ 0W | 約 6W（終段側が熱くなる） |

- <strong>許される熱抵抗。</strong>チャネル 110°C 以下・ケース内 40°C とすると全体で `(110 − 40) ÷ 3.5W = 20°C/W`。素子の 6.25°C/W（Pd 20W からの計算値、データシートで要確認）と接触面を引いて、**放熱器側は 12°C/W 以下**。
- <strong>取り付け。</strong>2SK4017 は基板に載せず、ケースの側板に取り付けて外側にヒートシンクを当てる。配線と取り付けは<strong>[製作ガイド 03章](02-build-guide.md#03-2sk4017-の取り付けとケース)</strong>。

## 04 M2 トーン生成と平滑フィルタ

MCU が PWM で 700Hz の正弦波を合成し、M2 はその PWM を平らにするだけ。落とすべき高調波が最初から無いので、**抵抗2本とコンデンサ2個**で足りる。オペアンプも半固定抵抗も要らない。インピーダンスは低いほうが送信機の中で有利なので 1kΩ を使う。

![MCU の250kHz PWM出力を1kΩと47nFの2段RCフィルタで平滑し、700Hzの正弦波として変調器へ渡す回路図](img/design-fig04.svg)

**図 4**　直流も通すので、PWM のデューティ平均がそのまま搬送波レベル（M3 の基準電圧）になる。交流結合が無いぶん、キーイング時の過渡もリセット後のふらつきも起きない。

### PWM に求める仕様

M2 の出力は `3.3V × デューティ × |H|`、M3 が 1/3.2 分圧で帰還しているので **ドレイン電圧 = M2 出力 × 3.2**。ここから、回路側が MCU に要求する値が決まる。**これが回路とファームウェアの境界**で、以下はすべて回路の定数から導いた値。

| 項目 | 値 | 導出 |
|---|---|---|
| PWM 周波数 | 250 kHz | M2 で −74.7dB 減衰する（下表）。これより低いと残留が増える |
| デューティ分解能 | 8 bit 以上 | 1LSB がドレイン 41mV ＝ 搬送波 3.6V の 1.1% |
| デューティ更新レート | 25 kHz | 折返しが 24.3kHz に出て M2 で −34.8dB 落ちる（下表） |
| 搬送波点のデューティ | 0.341 | 1.125V ÷ 3.3V（公称でレジスタ 87。校正後の実機は 84）。ドレイン 3.6V ＝ 出力 1.5W |
| 変調度 80%・700Hz の振幅 | ±0.311 | 0.90V ÷ (3.3V × 0.877)。700Hz での `\|H\|` 込み |
| A2A の運用範囲 | 0.030 〜 0.652 | 上の2つから決まる |
| **デューティの絶対上限** | **0.730** | ソースフォロワの上限 `8V − 1.5A × 0.1Ω = 7.85V` は `7.85 ÷ 3.2 ÷ 3.3 = 0.743`。そこから余裕を取ってレジスタ **187**（ドレイン 7.71V。校正後の実機は 181）。ファームウェアはここを超えてはならない |
| フルスケールで取れる振幅 | 1.45 Vpk | 必要な 0.90Vpk の 1.6 倍。余裕あり |

**搬送波レベルも変調度もソフトウェアの数値で決まる**ので、半固定抵抗が要らない。実測して定数を書き換えるだけで追い込める。LEDC の設定・デューティ写像・エンベロープ整形・動作モードといった実装側の規定は、**別資料のファームウェア仕様書**にまとめた。

### 残留スプリアス

| 成分 | 周波数 | RC 減衰 | 出力 |
|---|---|---|---|
| 700Hz トーン | 700 Hz | −1.14 dB | **0.90 Vpk** |
| 更新レートの折返し | 24.3 kHz | −34.8 dB（+ZOH −30.8dB） | −64.5 dBc |
| PWM 基本波 | 250 kHz | −74.7 dB | −73.3 dBc |

トーンは合成された正弦波なので、方形波方式で問題になった 3倍波（2.1kHz）は原理的に出ない。残るのは PWM と更新レートの残留だけで、どちらも −64dBc 以下に収まる。

### 送信の開始と停止：順序は回路が決めている

この構成には **2つのスイッチ**しかない。`Si5351A の CLK0`（搬送波そのもの）と、`PWM のデューティ`（ドレイン電圧＝出力電力）。この2つを動かす順序は回路の都合で決まっていて、選択の余地がない。

- <strong>開始は CLK0 が先、デューティが後。</strong>CLK0 が来ていてもドレインが 0V なら電波は出ないので、この間に PLL のロックを待てる。
- <strong>停止はデューティが先、CLK0 が後。</strong>デューティを落としてから 10ms ほど待ち、ドレイン電圧が 0 付近まで下がってから CLK0 を切る。

> [!WARNING]
> **順序を逆にしてはいけない理由**
>
> - <strong>クリックが出る。</strong>搬送波を先に切ると、1.5W の出力を瞬間的にゼロにすることになる。ステップ応答の側波帯が数十 kHz にわたって広がる。ドレインを先に落としておけば、切る瞬間の電力がほぼゼロなので何も起きない。
> - <strong>Mod ノードが下がらなくなる。</strong>ソースフォロワは電流を流し出せても**吸い込めない**。ドレイン電圧が下がるのは終段が電流を引くからで、ドライブを先に切ると終段が電流を引かなくなり、Mod ノードは 3.6V のまま浮いたまま残る。

具体的な手順（デューティを落とす時間、待ち時間、状態機械）はファームウェア仕様書の規定による。なお A2A のキーイングでは**搬送波を切らずトーンだけを断続させる**ので、この停止手順が走るのは運用の終わりだけになる（11章「運用の注意」）。

### ドレインを 0V にするだけでは止まりきらない

終段のドレインを 0V にしても、ドライブが生きている限り **Crss（ゲート-ドレイン間容量）経由で漏れる**。ゲートの RF は約 2.7Vpk なので、Crss を 1〜2pF とすると

`I = ω·Crss·Vg = 2π × 145MHz × 1pF × 2.7V = 2.5mA` → 負荷 3.5Ω で 8.6mVpk → <strong>約 10〜40µW（−45〜−52dBc）</strong>。

1.5W に対しては小さいが、近くの局には確実に聞こえる。**完全に止めるには CLK0 を切る必要がある**。逆に言えば、A2A のキーイングで搬送波を出したままにする方式なら、この漏れは問題にならない。

> [!WARNING]
> **搬送波の停止はファームウェアに依存する**
>
> - AE-Si5351A-B には **OEB ピンが出ていない**（8ピンは VDDO / SCL / SDA / GND / CLK0-2 / VDD）。搬送波を止める手段は I2C レジスタ経由しかない。
> - したがって **MCU がハングすると送信し続ける**。ウォッチドッグを必ず入れ、リセット時は GPIO が Hi-Z になってデューティ 0＝出力ゼロに落ちることを利用する（下の「電源投入時とリセット時」）。
> - 確実な最終手段は <strong>SW_Power（主電源）</strong>。運用中に手が届く位置に置く。
> - ハードウェアの送信禁止を追加するなら、**ドライバのベースバイアス（R31 620Ω）を GPIO で GND へ短絡する**のが一番安い。2SC4703 が止まり、終段へのドライブが消える。

> [!WARNING]
> **電源投入時とリセット時**
>
> - PWM が動き出す前、GPIO は Hi-Z か Low になる。M2 は直流を通すので、そのまま M3 の基準が 0V になり、**送信は止まる**（安全側）。
> - 逆に GPIO が High に張り付くと基準が 3.3V になり、M3 が振り切れて終段に 8V がかかる。ただし 8V レールが上限なのでそれ以上は上がらず、しかもその状態では終段に電流が流れないので破壊には至らない。**本来の保険はファームウェア側のデューティ上限**（運用 0.652 / 絶対 0.730）で、これを超えないようにコードで縛る。
> - 念のため M2 の入口に **100kΩ のプルダウン**を入れておくと、Hi-Z のときに確実に 0V へ落ちる。

**ADC が使えるのは GPIO0〜GPIO2（D0〜D2）だけ**という ESP32-C6 の制約があるので、アナログ2系統はここに固定される。PWM は GPIO マトリクス経由なので任意のピンに出せる。

押しボタンの働きはモードによって変わる（音声送信 / ARDF送信 / 周波数切替 / コールサイン編集 / ARDF識別信号）。**モード構成と各ボタンの具体的な動作はファームウェア仕様書**に規定した。主電源は番号を振らず **SW_Power**（09章）とし、押しボタンだけを 0 から連番にしてある。

> [!WARNING]
> **PWM を出すピンの選び方**
>
> - PWM の出力はそのまま M2 を通って M3 の基準電圧になり、**ドレイン電圧 = その電圧 × 3.2** で終段に直結している。したがって**起動中にそのピンがどう振る舞うかが、そのままドレイン電圧になる**。
> - <strong>UART0 の TX（GPIO16 / D6）を使ってはいけない。</strong>ROM ブートローダが起動時にログを出力し、しかも UART のアイドルは High なので、起動中ずっと 3.3V に張り付く。ドレインが 8V レールまで振り切れる。ROM の出力は eFuse で制御されるためソフトウェア設定では止められない。
> - UART0 の RX（GPIO17 / D7）は入力として初期化されるだけだが、内蔵プルアップが有効になると外部 100kΩ プルダウンとの分圧で 2.3V 程度が乗る。
> - <strong>実際に使っているのは GPIO2（D2）。</strong>ストラッピングピンではなく（ESP32-C6 のストラッピングは GPIO4 / 5 / 8 / 9 / 15）、ブート時に UART などの機能も出ない。ただし ADC1 CH2 と LP_GPIO2 を兼ねていて、**リセット直後の内部プルアップ／プルダウンの状態はデータシートで確認できていない**。内部プルアップが効いていると、外部 100kΩ との分圧で M3 の基準が持ち上がる。**電源投入とリセットのときに TP2（変調器出力）が 0V のままであることを、実機で確かめること**（PCB の立ち上げ手順に入れる）。当初の設計は GPIO21（D3）だった。
> - いずれの場合も CLK0 が停止していて終段にドライブが無いため電流が流れず、実害には至らない（上記「電源投入時とリセット時」）。とはいえ振れないピンを選ぶに越したことはない。

### 直流阻止コンデンサ

1000pF（1608、C0G）。整合素子ではなく単なる直流阻止なので、ESL 込みの 145MHz でのリアクタンスが 0.55Ω＝50Ω の 1.1% と十分小さいことが条件。470pF 以上で特性は飽和するので 1000pF で余裕がある。

> [!WARNING]
> **置く順序：直流阻止 → パッド**
>
> - Si5351A の出力は 0〜3.3V を振る CMOS ドライバなので、出力ピンには **直流平均 1.65V** が乗っている。
> - ここにパッドを直結すると、並列 300Ω に **5.5mA の直流**が流れる。8mA ドライブ設定に対して 69% で、ドライブ能力を大きく食われるうえ High レベルも下がる。
> - 1000pF をパッドの**前**に置けば、パッドは交流だけを見るのでこの問題が起きない（ADR-006）。

### パッド

Si5351A の出力は CMOS ドライバなので、出力インピーダンスが 50Ω ぴったりではない。定数k形フィルタは終端インピーダンスに敏感なので、パッドで 50Ω を保証しておく効果が大きい。あわせて、フィルタが反射した高調波を吸収して Si5351A の出力段に戻さない役目もある。

| 減衰量 | π型（直列 / 並列×2） | T型（直列×2 / 並列） |
|---|---|---|
| 2 dB | 12Ω / 430Ω | 5.6Ω / 220Ω |
| **3 dB** | **18Ω / 300Ω** | 8.2Ω / 150Ω |
| 4 dB | 24Ω / 220Ω | 11Ω / 100Ω |
| 6 dB | 36Ω / 150Ω | 16Ω / 68Ω |
| 10 dB | 75Ω / 100Ω | 27Ω / 36Ω |

まずは **3dB**（π型：直列 18Ω / 並列 300Ω×2）で組み、ドライブが足りなければ抵抗を差し替えて減らす。0dB（直結）まで戻せるパターンにしておく。

### 使用するモジュールと周波数の決め方

秋月 **AE-Si5351A-B**。ピン配置は `1=VDDO / 2=SCL / 3=SDA / 4=GND / 5=CLK0 / 6=CLK1 / 7=CLK2 / 8=VDD`。基準は **25MHz**（FA-128）。**オンボードレギュレータもプルアップも載っていない**ので、VDD / VDDO には 3.3V を直接与え、I2C のプルアップ（10kΩ×2）は基板側で用意する。VDD の推奨は 2.5〜3.3V なので、3端子の出力誤差込みで 3.4V を超えないこと。CLK1 / CLK2 は未使用なのでレジスタで停止させておく。

周波数の設定で決まるものが2つある。どちらも**フィルタでは消せない**ので、ファームウェア側で押さえる。

- <strong>搬送波のすぐ近くのスプリアス。</strong>PLL が分数分周だと搬送波の近傍にスプリアスが出て、入口の LPF も出口の LPF も素通りする。VCO（PLL）と MultiSynth の**両方を整数**にすると最小になる。25MHz 基準で 144MHz 帯（PLL 864〜876MHz）に入る整数 PLL は **875MHz（×35）だけ**で、÷6 の **145.833MHz** が両方整数になる唯一の点。
- <strong>2倍波。</strong>上のフィルタは 290MHz で −7dB しか取れないが、**MultiSynth を偶数整数（÷6）にすれば出力デューティがほぼ 50% になり、2倍波は原理的にほとんど出ない**。
- したがって、145.833MHz 以外の周波数でも **MultiSynth は偶数整数 6 に固定し（PLL = 出力 × 6 = 864〜876MHz）、PLL 側を小数分周にする**。デューティ 50% が保証され、分数分周のスプリアスもこの条件で最小になる。運用周波数を決めるときは、この条件とバンドプランを突き合わせる。

## 06 ドライバ段（2SC4703）

### 実装と調整

- <strong>エミッタの接地が最優先。</strong>22Ω とバイパス 2200pF は 2SC4703 の直下に置き、グランドまで最短で。ここのインダクタンスがそのまま負帰還になって利得と安定度を削る。
- <strong>入力側の L7 は必ず可変に。</strong>2SC4703 の 144MHz での S パラメータが公開されていないため、Zin は推定値（約 15 − j25Ω）。終段の入力整合（07章）と同じ理由で、実測で追い込む前提。
- <strong>出力側は L6 だけで合わせる。</strong>コレクタ負荷はロードラインで決まる実数（281Ω）なので、調整手順書の抵抗置換法（270Ω）で素子なしに追い込める。ただし **281Ω → 50Ω の L 網に必要な並列 C は 8.5pF と小さく、パッドや配線の浮遊容量だけで大半が埋まる**。試作では浮遊が 6.63pF あり、トリマ C39 は最小容量に回しても行き過ぎたので実装しないことにした（ADR-020）。v0.1 基板は Q3 の放熱のためにコレクタに小さなベタがあり、浮遊はさらに 0.5〜0.8pF 増える。C39 は実装せず、L6 で合わせる（[調整手順書の手順 6](03-bring-up.md#手順-6--ドライバj11-は開けたまま始める)）。
- <strong>圧縮させて使う。</strong>利得は 18〜22dB 見込めるので、必要な 15.3dB に対して 3〜6dB の圧縮がかかる。これが終段へのドライブを安定させる。入力側にパッドを追加する場合（05章）もこの圧縮が効いて出力が動きにくい。
- <strong>直流阻止はドライバ側に置く。</strong>1000pF が L6 の前でも終段の整合回路の入口でも、RF 的には等価（144MHz で 1.1Ω）。ただしドライバ側に置けば、段間の配線が直流 0V になる。段間で切って電力計を当てられるし、この配線が半田ブリッジでグランドに落ちても 8V レールを短絡しない。<strong>直流阻止は、直流が乗っている側の段に持たせる。</strong>
- <strong>発振チェック。</strong>fT が 6GHz あるので UHF での発振に注意。ドライブを切った状態、バイアスを振った状態の両方で SDR に何も出ないことを確認する。怪しければベース直列抵抗を 10Ω → 22Ω に増やす（利得は 1〜2dB 落ちるが余裕がある）。

## 07 終段の整合回路

**出力はロードライン計算**（3.5Ω → 50Ω）、**入力はデータシートの実測 Zs**（175MHz・Idq=500mA の値を代用）で定数を出し、どちらも実測で追い込む。出力側は抵抗置換法で素子なしに合わせられるが、入力側は C級のゲートが小信号では導通しないため、**大信号を入れてから決める**（下記）。

![2SC4703からの50Ω入力を33pFと33nHで終段ゲートへ整合し、ドレイン側は14nHと約83pFで50Ωへ変換してLPFへ渡す終段まわりの回路図](img/design-fig08.svg)

**図 8**　入力側は 50Ω をゲート（データシート実測ベースで Zs≈14+j9Ω、ADR-016）へ、出力側はドレインが必要とする 3.5Ω 前後（同ZL≈5−j3Ω）を 50Ω へ変換する。ドレインへの給電チョーク（0.47µH 空芯）は 145MHz で 471Ω あり、3.5Ω の負荷に対して 0.7% しか影響しない。

### 出力：ロードラインから決まる

C級増幅段が必要とする負荷抵抗は `R = (Vd − Vknee)² / (2·Pout)`。

| 動作点 | Vd | Pout | 必要な負荷 |
|---|---|---|---|
| 無変調（搬送波） | 3.6 V | 1.5 W | 3.0 Ω |
| 変調ピーク | 7.2 V | 6.0 W | 3.6 Ω |

出力が Vd² に比例して動くので、**搬送波時とピーク時で最適負荷がほとんど同じ**になる。ドレイン変調が素直に働くのはこのためで、どちらかに合わせれば両方で最適になる。設計値は **3.5Ω** とした。

| 素子 | 値 | 備考 |
|---|---|---|
| L10 | 14 nH | 1.3 Arms 流れる。空芯・φ3mm 心棒に 2T（[製作ガイド 04章](02-build-guide.md#04-手巻きコイルの製作)）。**可変**。実測で追い込んだ値はリード込みで **14.1nH**（[調整手順書 04章](03-bring-up.md#04-試作で決まった値調整の出発点)） |
| C50（DC ブロック） | 0.01 µF | C0G 50V / 3216。0.01µF は ESL と自己共振して 145MHz では容量ではなく **約 1Ω の誘導性**になるが、L10 に直列に足されるだけなので伸縮で吸収できる |
| C52 / C53（並列 C） | 合計 約 83 pF | **56pF 固定 + 30pF トリマ**（浮遊込みで約 62〜91pF）。3.3Ω → 50Ω に必要な値は 82.6pF で、実測もそこに落ちた。Q4 を載せると Coss の影響で 86pF 前後へ動く見込み（ADR-021） |
| ロードQ | 3.6 | 帯域 40MHz。2倍波も 6〜10dB 落ちる |

Coss は 40〜250pF のどこにあっても L10 は 13〜14.5nH に収まる（ドレイン側が 3.5Ω と低インピーダンスなので摂動が小さい）。<strong>出力整合は計算値で作ってよい。</strong>ただしドレイン変調では Vd が動くたびに Coss も変化するので、整合は搬送波点（3.6V）で最適化する。

### 入力：こちらは敏感なので可変にする

データシートの実測 Zs（スミスチャート）で 175MHz — 本機の 144MHz に最も近い実測点 — は **Zs = 13.90 + j9.38Ω**。これを L 網（直列 L → 並列 C → 50Ω）で解くと、直列 L は **29〜35nH**、並列 C は **29〜36pF**。**L14 = 33nH**（φ3mm に 4回、[製作ガイド 04章](02-build-guide.md#04-手巻きコイルの製作)）と **C60 15pF 固定 ＋ C61 30pF トリマ**（合計の可動域 約 20〜45pF）がこの範囲に対応する。導出は ADR-016、L14 の心棒は ADR-018、並列 C の構成は ADR-019 を参照。

ただしこの Zs は 175MHz・Idq=500mA（AB級寄り）というデータシートの測定条件での値で、本機の 144MHz・Idq≈0（C級）とは条件が異なる。**L14 は必ず空芯の可変コイルにして実測で追い込む**こと。

> [!WARNING]
> **小信号の S11 では入力整合を追い込めない（実測で判明）**
>
> - Idq ≈ 0 にバイアスした C級の終段は、NanoVNA の −13dBm 程度ではゲートが閾値に全く届かず、**完全にオフのまま**。見えているのは Ciss とゲート配線抵抗だけになる。
> - 試作での実測では、終段の入力から見て <strong>3.8 + j15.9Ω（リターンロス −1.2dB）</strong>。逆算するとゲート単体は <strong>約 1.7 − j32Ω（Ciss 約 34pF）</strong>で、実部がデータシート値 13.9Ω の 1/8 しかない。
> - 実部 1.7Ω を 50Ω に変換するには並列 C が **約 118pF** 要り、C60 + C61（最大 45pF 程度）では原理的に届かない。L14 はすでにほぼ最適（必要 46nH に対し密着巻き 48nH）で、コイルをどう伸縮しても −1.4dB までしか改善しない。
> - <strong>並列 C を 118pF に増やしてはいけない。</strong>大信号ではゲートが導通して実部が上がり、必要な C は設計値の 35pF 付近に戻る。小信号に合わせると大信号で外れる。
> - したがって入力整合（L14 / C61）は **大信号を入れて「同じ出力を得るのに必要なドライブが最小になる点」で決める**（[調整手順書の手順 7](03-bring-up.md#手順-7--終段と-lpfj13-は開けたまま始める)、ADR-023）。小信号の S11 は発振していないことの確認にだけ使う。

### ゲートバイアス回路

ドレイン変調では、出力が `Vd²` に比例することが前提になる。そのためには終段が**飽和した C級**で動いている必要があり、無信号時のドレイン電流 Idq はほぼ 0 でなければならない。Idq が残っていると変調の谷でキャリアが抜けきらず、下側変調度が頭打ちになる。したがってゲートバイアスは「しきい値の少し下」に置く。

LDMOS の Vgs(th) はロットで 1.5〜2.5V ばらつくので、**固定値では決め打ちできない**。半固定抵抗で 0〜3.2V を可変にして、実測で追い込む。逆に Idq ≈ 0 で使う限り熱暴走の心配がないので、AB級リニアアンプのようなダイオードやサーミスタによる温度補償は不要。

![8Vレールから15kΩと10kΩ半固定抵抗で0から3.2Vの可変分圧を作り、10µF・0.1µF・1000pFでバイパスし、220kΩのブリーダを付けて終段のゲートバイアスへ送る回路図](img/design-fig09.svg)

半固定抵抗は<strong>ポテンショメータ結線（3端子とも使う）</strong>にする。可変抵抗結線（ワイパと片端を短絡）にすると、ワイパが浮いたときに全抵抗が残って中途半端な電圧がゲートに出る。3端子結線ならワイパ断線でノードが開放になり、R34 が 0V へ引いてくれる。

### 安定度と実装

- <strong>ソース接地が最優先。</strong>SOT-89 のタブ直下にサーマルビアを兼ねたビアを多数打ち、太く短くグランドへ。ソースのインダクタンスは利得と安定度を直接殺します。ここが一番の勘所です。
- <strong>低周波発振の対策。</strong>LDMOS は低い周波数ほど利得が高く、バイアス回路の共振で発振します。ゲートバイアスは `1µH + 100Ω` を直列に入れて供給します。バイアス源が 6kΩ の分圧なので、これ自体がダンピング抵抗として働きます（別途 10Ω を入れる必要はありません）。
- <strong>ゲートに直列抵抗は最後の手段。</strong>2〜4.7Ω を入れると確実に安定しますが、ゲート抵抗が 2Ω しかないので利得を 3dB 近く失います。まずバイアス回路のダンピングで対処を。
- <strong>チョークに積層（多層）チップインダクタを使わない。</strong>積層品はフェライトを焼き固めた構造で、1µH で SRF 50MHz、2.2µH で 30MHz 程度しかない。145MHz では共振点のはるか上、しかも損失が大きいので**抵抗として振る舞う**。ドライバのコレクタに使うと 145MHz でのインピーダンスが 90Ω しかなく、負荷 281Ω に対して**出力の 63% を熱にする**。ゲートバイアス側でもドライブを 15%（−0.7dB）食われる。**巻線（ワイヤワウンド）型を指定すること** — 同じ 1µH でも SRF 200MHz、145MHz で 1.9kΩ、損失 0.1% に収まる。
- <strong>素性の分からないチップインダクタは実測してから使う。</strong>NanoVNA の2ポート間に直列に挟んで S21 を見る。直列インピーダンスは `|Z| = 100 × (1/|S21| − 1)` なので、145MHz で **巻線型なら −26dB 前後、積層型なら −7dB 前後**と桁違いに差が出る。LC メーターは 100kHz で測るためどちらも同じ値を示し、区別できない。
- <strong>チョークをフェライトビーズで代用しない。</strong>ビーズは 145MHz でも 150Ω 程度の*抵抗*で、直流電流で値が崩れる。空芯 0.47µH の 471Ω（純リアクタンス）とは別物で、ドレインに使うと電力を食い、変調電流でインピーダンスが揺れて包絡線が歪む。**ドレイン給電は空芯で自作する**（[製作ガイド 04章](02-build-guide.md#04-手巻きコイルの製作)）。市販品を使うなら Isat 2A 以上 / DCR 0.1Ω 以下 / SRF 300MHz 以上が条件だが、この3つを同時に満たすチップ品は入手しにくい。ビーズは電源ラインの高周波阻止に使う部品。
- <strong>R36 を外したまま送信しない。</strong>R36 は LPF を単体で掃引するための切り離し点（調整手順書）。外すと終段が無負荷になり、ドレイン電圧が跳ね上がって素子を壊す。

### 追い込みの手順

終段の整合とゲートバイアスの追い込みは、全体の立ち上げの中に位置づけて**調整手順書**にまとめた。出力側（L10 / C53）を抵抗置換法で先に決め、入力側（L14 / C61）は大信号で決める。その後 2〜3 往復させる。試作で決まった値は <strong>[調整手順書 04章](03-bring-up.md#04-試作で決まった値調整の出発点)</strong>。

### 作るときの注意

- <strong>コイルは隣同士の軸を直交させ、直径の2倍以上離す。</strong>一般的な作法なので守っておく。基板は L12 だけ 90° 回したレイアウトにしてある。
- <strong>ただし試作の 433MHz の頭打ち（−41dB）はコイル間の結合が原因ではなかった。</strong>L13 を基板に垂直に立てても、L12 を垂直に立てても 433MHz はほぼ動かなかった。一方で L12 の片脚を浮かせてフィルタの鎖を切ると −56dB まで下がり、ケーブルを基板から外すと −65dB になる。つまり**信号はフィルタの素子を通って漏れている**。有力な候補はシャント C のグランド帰路のインダクタンス（パッド〜ビア）だが未検証。v001 でグランド処理を見直す課題として残す（ADR-022）。
- <strong>入出力間の距離とシールド。</strong>入口と出口を基板の対角に配置し、可能なら仕切り板を1枚入れる。
- <strong>コンデンサは C0G(NP0) 必須。</strong>X7R は損失と電圧係数で使えません。中央の2箇所には 0.9Arms、33Vp がかかるので、100V 品を 2個並列（C55/C56、C57/C58）にします。
- <strong>コイルは伸縮で微調整。</strong>巻き数を変えず、長さを±1mm 変えると 10% ほど動きます。インダクタンスが ±10% ずれても挿入損失 0.4dB / リターンロス 16dB 程度に収まるので、神経質にならなくて大丈夫です。
- <strong>チップインダクタでも可。</strong>68nH / 82nH で代用できますが、Q が 60 程度に落ちるため挿入損失が 0.7dB（約15%の電力損）に増えます。空芯のほうが有利です。

### 電源系統の注意

- <strong>Si5351A は 3.3V 品。</strong>VDD の絶対最大が 3.60V。レギュレータを載せたブレークアウト基板でない限り、3.3V 以外を入れてはいけない。使うモジュールにレギュレータが載っているかは実装前に必ず確認する。
- <strong>LCD は +3.3VA から取る。</strong>AQM0802A（ST7032）は液晶バイアス用のチャージポンプを内蔵していて常時スイッチングしているので、周波数基準の +3.3VB に相乗りさせない。消費は 0.4mA なので MCU レールへの影響は無視できる。**I2C のプルアップ（R2 / R3）は +3.3VA に取る**（2026-10-15 に +3.3VB から変更）。Si5351A の電源に通信のたびの電流が流れず、8V が無い状態（USB だけでの書き込み・デバッグ）でも ESP32 と LCD が通信できる。Si5351A の SCL / SDA が自分の VDD より少し高い "H" を受けることになるので、絶対最大定格（3.6V までのはず）をデータシートで確認しておく。
- <strong>FB2 は「電源を綺麗にする」ための部品ではない。</strong>フェライトビーズは 10MHz 以下では素通しなので、LDO の出力ノイズには何も効かない。効くのは **145MHz そのもの**で、役割は2つある。<br>① <strong>Si5351A の出力電流を閉じ込める。</strong>CLK0 は 8mA の CMOS ドライバで、その電流は VDDO から供給される。ビーズが無いと 145MHz の電流が 3.3VB の配線（20nH ≒ 18Ω）を通って電源部まで戻り、そこから放射する。<strong>これは出力 LPF の外側の経路なので、LPF では消せない。</strong>ビーズ（145MHz で 150〜200Ω）を入れると漏れは `18/150` ≒ **17dB** 減る。<br>② <strong>終段の 1.5W を電源配線が拾うのを防ぐ。</strong>拾った RF が VDD に乗ると出力にスプリアスが出る。モジュールがピンヘッダ実装で電源経路にインダクタンスがあるぶん、なおさら効く。
- <strong>FB2 を抵抗で代用しない。</strong>10Ω を入れると 38mA で 0.38V 落ちて 2.9V になり、Si5351A の動作範囲を割る。**直流では 0Ω、145MHz では 150Ω** という性質そのものが必要。
- <strong>Si5351A の 3.3V は MCU と共有しない。</strong>ESP32C6 は WiFi/BLE で数百 mA のパルス電流を引く。周波数基準を MCU と同じ降圧コンバータの出力にぶら下げると、その負荷変動とスイッチングリプルが LDO の PSRR を通らずそのまま VDD に乗る。**8V レールから 82Ω を介して専用 LDO** を立て、直近に 0.1µF + 10µF を置く。
- <strong>5V レールは作らない。</strong>XIAO ESP32C6 は 3V3 ピンから直接給電できるので、5V を経由して内蔵レギュレータで落とす必要がない。BP5293-33 が 3.3V を出して MCU 専用とする。
- <strong>Si5351A の LDO を 8V から取っても問題ない理由。</strong>8V レールは変調で 0〜1.5A に振れるが、レール上のリプルは 100mV 程度で、LDO の PSRR（1kHz で 50dB 前後）と 82Ω + 10µF の前置フィルタ（fc 194Hz）を通ると VDD では 1mV を切る。抵抗を入れることで LDO の入出力差が 1.7V に落ち、SOT-23 パッケージの損失も 179mW → 65mW になる。
- <strong>8V レールのピーク時の落ち込みを実測する。</strong>変調ピークで出力 7.2V を出すには、パス MOSFET のドロップ（0.2V 程度）込みで 8V レールが 7.4V 以上を保つ必要がある。RT8250 は 3A 品なので電流は足りるが、1kHz の負荷変動に対する応答は出力コンデンサ次第。足りなければ 220〜470µF を追加するか、レールを 8.5V に上げる（MOSFET の損失は 3.5W → 3.9W）。
- <strong>17.4V は必ず電池側から。</strong>NJW4190M は倍電圧なので、8V レールから取ると最大 16V 弱にしかならず 17.4V を出せない。
- <strong>バッテリー電圧は MCU で監視する。</strong>100kΩ / 18kΩ の分圧（R4 / R7）で D0 の ADC へ入れる。常時 144µA 流れるが、3Ah に対して約 2400 時間ぶんなので許容範囲。**下限は 10.5V** — ここを割ると NJW4190M が 17.4V を出せず、降圧DC-DC が音を上げるより先に変調器のオペアンプが動作範囲を外れる。ファームウェア側で送信を禁止する。
- <strong>送信ピークで 0.3〜0.5V は落ちる。</strong>1.05A 引くので、電池の内部抵抗とケーブルぶんが落ちる。監視の判定を瞬時値で行うとキーイングのたびに送信が止まるので、平均値で判定すること。
- <strong>過電流保護はポリスイッチ（PPTC）で足りる。</strong>セル側の破局的な故障はパック内の BMS が見るので、基板側の保護に求められるのは「基板や配線が焼ける前に電流を切る」ことだけ。復帰型なので、運用中に落ちても予備を持ち歩かなくてよい。**保持電流 1.85A / 定格 30V 級**を選ぶ。直列抵抗 0.05〜0.15Ω は、ピーク 1.05A で 0.05〜0.16V の電圧降下にしかならない。
- <strong>ポリスイッチは温度で保持電流が下がる。</strong>周囲 60°C では 23°C 定格の 65〜70% しか流せない。終段の MOSFET が 3.5W を出す密閉筐体では実際に 50〜60°C になるので、`1.05A ÷ 0.65 = 1.6A` を下回らない品を選ぶ。1.0A や 1.35A 品では変調ピークで誤動作する。
- <strong>3V3 ピンは内蔵レギュレータの出力でもある。</strong>USB を挿したまま外部 3.3V を入れると、内蔵レギュレータと BP5293-33 が同じノードを取り合う。**BP5293-33 → 3V3 の間に 2ピンのジャンパ（J12）を入れて、書き込み時は外す**。BP5293-33 は出力固定 3.3V なので、RT8250 で使えた「出力を高めに設定してダイオードで落とす」手は使えない — ジャンパで確実に切り離すのが唯一の方法（ADR-014）。
- <strong>USB 接続中は Si5351A も終段も無電圧になる。</strong>この構成では書き込み時に主電源を切るので、送信部が動かない状態でファームを焼くことになる。動作確認は主電源を入れ直してから行う。

## 11 設計上の注意

### 回路の落とし穴

- <strong>ドレインに大容量のバイパスコンデンサを入れない。</strong>通常の PA なら 100µF を入れる場所ですが、ここは音声を通す経路そのものです。100µF を 1kHz・3.6V で振るには `I = C·dV/dt = 2.3A` 必要で、変調器が供給できず変調が潰れます。**0.1µF まで**。RF の帰り道は RFC の手前で確保します。
- <strong>終段ドレインの瞬時最大電圧は約 14.4V。</strong>C級では変調ピーク電圧の約 2 倍が瞬間的にかかります。変調ピーク 7.2V での通常運用と同じ値なので問題ありません。ドレインの直流電圧は 8V レールが上限を決めるので、それ以上には上がりません。
- <strong>変調器 MOSFET の損失は最大 3W 前後。</strong>ドレイン 4V で最大になり、搬送波（3.6V）はそのすぐ近く。試作の実測から約 2.9W、変調中の平均は約 2.1W。**3.5W で設計**し、ケース側板＋外付けヒートシンクで逃がす（[製作ガイド 03章](02-build-guide.md#03-2sk4017-の取り付けとケース)）。
- <strong>負変調は 70〜85% で頭打ちになりやすい。</strong>変調度 80% なら谷のドレイン電圧は `3.6 × 0.2 = 0.72V` で、膝電圧（約 0.6V）のすぐ上です。ここで終段は飽和 C級から外れるのに、ゲートには満振幅のドライブが入り続けているため、残留導通と Crss の素通りでキャリアが抜けきりません。**A2A ではこれで十分実用**なので、本機はここを追わない（ADR-017）。

### 運用の注意

- <strong>アンテナ未接続で送信しない。</strong>ピークで 6W 出るので終段が飛びます。調整は必ずダミーロード（50Ω / 10W）で。野外に放置するなら簡易的な反射電力検出で送信を止める仕組みがあると安心です。
- <strong>トーンは必ず正弦波で。</strong>方形波で変調すると ±3kHz、±5kHz と奇数次側波帯が延々と出て占有周波数帯幅をオーバーします。キーイングの立ち上がり・立ち下がりも 5ms 程度なまらせるとクリックが出ません。
- <strong>A2A は搬送波を出しっぱなし。</strong>キーイングするのはトーンだけで、キャリアは連続。ここを間違えると A1A になります。

> [!WARNING]
> **運用前に必要な手続き**
>
> - 自作機のため、TSS または JARD の保証認定（工事設計書 + スプリアス確認）を経てから変更申請が必要。
> - スプリアス発射の強度は必ず実測で確認する。手元の測定は RTL-SDR ＋ 減衰器で行うが、保証認定でスペアナ実測を求められる場合があるので、JARD のスプリアス確認保証の要件は事前に確認する。2倍波が落ちきらない場合の追加策は ADR-007、3倍波は ADR-022。
> - 144MHz 帯のバンドプランで A2A が使える区分かを確認してから送信すること。

## A 付録：マイク入力（A3E への拡張）

現時点では A2A のみを対象とする。将来 A3E（音声 AM）に広げる場合の入り口だけを、確定した数値として残しておく。**マイク出力をアナログのまま Audio ノードへ入れるのではなく、MCU の ADC に入れてソフトウェアで扱う**。理由は下記。

### Audio ノードに必要な信号

M3 は帰還で 1/3.2 に分圧しているので、**ドレイン電圧 = Audio × 3.2** がそのまま成り立つ。ここは A2A のトーンと共通の仕様。

| 項目 | 値 | 意味 |
|---|---|---|
| 直流 | 1.125 V | 搬送波レベルそのもの（ドレイン 3.6V） |
| 交流 | ±0.90 Vpk | 変調度 80% |
| 下限 | 0.225 V を切らない | ここで変調度 100%。割るとキャリアが切れてスプラッタ |
| 上限 | 2.025 V を超えない | ドレイン 6.5V 相当。8V レールが構造上の天井 |
| 帯域 | 300 Hz 〜 3 kHz | 占有帯域を抑える |

**直流が搬送波レベルである**ことがこの回路の特徴。マイクアンプの出力を交流結合でそのまま入れると直流が失われ、搬送波が消える。

### マイクが出せるレベル

秋月 **AE-SPU0414**（Knowles SPU0414HR5H-SB）。感度 −22dBV/Pa（ゲインジャンパ短絡時）＝ 94dB SPL で 79mVrms。出力の直流バイアス 0.93V、出力インピーダンス 400Ω。

| 状況 | 音圧 | 出力 |
|---|---|---|
| 5cm で普通に話す | 85 〜 90 dB | 25 〜 50 mVrms |
| 音声のピーク（波高率 12dB） | — | **100 〜 200 mVpk** |
| モジュール自体の飽和 | 105 dB 付近 | バイアス 0.93V から下へ約 0.5V |

必要な 0.90Vpk まで持ち上げるゲインは <strong>6〜20倍（16〜26dB）</strong>。ただしこの倍率をアナログで固定するのは筋が悪い（次項）。

> [!WARNING]
> **アナログでやらない理由**
>
> - <strong>過変調が最大の問題。</strong>音声は波高率が大きく、声量も距離も一定しない。ゲインを固定すると、小さい声では変調が浅く、少し大きい声で 0.225V を割る。**割った瞬間にキャリアが切れて占有帯域が一気に広がる**。リミッタは「あったほうがいい」ではなく必須。
> - <strong>窓が非対称。</strong>1.125V を中心に下は 0.225V まで、上は 2.025V まで。ダイオードクリップで作れるのは ±0.6V か ±1.2V の刻みで、欲しい ±0.90V に合わない。
> - <strong>直流台座を別に作る必要がある。</strong>反転増幅の + 入力に 1.125V を与える構成になり、オペアンプ・基準電圧・A2A との切り替えスイッチが増える。
> - ADC 経由なら、リミッタも帯域制限もコンプレッサも**数値で書けて、しかも絶対に守られる**。追加部品は抵抗3本とコンデンサ3個だけ。

### 接続

![マイクモジュールの出力を0.01µFで交流結合し、100kΩ2本で1.65Vにバイアスしたうえで、1kΩと47nFのアンチエイリアスフィルタを通してESP32C6のADCピンへ入れる回路図](img/design-fig13.svg)

**図 13**　追加部品は抵抗3本とコンデンサ3個だけ。`0.01µF` とバイアス分圧 50kΩ で **fc 318Hz のハイパス**になり、これがそのまま音声帯域の下端になる。ハンドリングノイズや吹かれも入り口で落ちる。`1kΩ + 47nF` は fc 3.4kHz のアンチエイリアス。マイクの電源は <strong>+3.3VA</strong> から取り、Si5351A の +3.3VB とは分けたままにする。**バイアス分圧の上側（R12）もマイクの電源と同じ「100Ω の後」から取る**（下記）。

### 処理はすべてソフトウェア側

やっていることは <strong>ADC → ソフトウェア処理 → PWM（1ビットDAC）</strong> の一本道で、**出力側の経路は A2A とそのまま共有する**。したがって A2A と A3E の違いは「変調入力に何を入れるか」だけになり、回路としては何も変わらない。

帯域制限（300Hz〜3kHz）、コンプレッサ、過変調を防ぐリミッタ、そして下記の周波数特性の補償は、いずれも**ファームウェア仕様書**の規定による。ここではハードウェア側の条件だけを挙げる。

> [!WARNING]
> **帯域内の傾きをソフトで補償する必要がある**
>
> - マイク側のアンチエイリアス（1次 LPF、fc 3386Hz）と出力側の M2（2段 RC）が、どちらも音声帯域の中で効いてくる。3kHz では **アンチエイリアスが −2.5dB、M2 が −8.5dB、合わせて −11dB**。
> - A2A（700Hz 単一トーン）では定数 0.877 で補正済みなので無関係だが、**A3E ではそのままだと音声がこもる**。
> - この傾きは既知の固定特性なので、ファームウェア側のイコライザで打ち消せる（1kHz 基準で 3kHz を +8.6dB）。M2 の定数を変えて傾きを減らす選択肢もあるが、fc を上げると PWM 残留の減衰（現状 250kHz で −74.7dB）が悪化する。<strong>A3E に着手する時点で改めて判断すること。</strong>

### 実装の注意

- **マイクの電源は +3.3VA に 100Ω + 10µF を介して与える**（R10 / C12、fc 約 160Hz）。ゲインが高いので、MCU レールのノイズがそのまま音声に乗る。C12 はモジュールの近くに置く。
- <strong>バイアス分圧の上側（R12）も R10 / C12 の接続点から取る。</strong>+3.3VA に直結すると、分圧で 1/2 になっただけのノイズがマイクを通らずに ADC へ入る（マイクの電源除去も RC も効かない）。R12 の電流は 16µA なので R10 での降下は 1.6mV。ESP32 の ADC は内部基準なので電源ノイズは打ち消されない。
- <strong>ゲインジャンパは短絡する。</strong>基板裏のジャンパを半田で埋めて +20dB 側にする。
- <strong>ADC のバイアスは 1.65V。</strong>音声のピークが ±100〜200mV 程度なので 12bit のレンジの数% しか使わない。**実効分解能は 9bit 弱**まで落ちるので、ソフトウェア側のコンプレッサは「あると良い」ではなく実質必須になる。
- <strong>アンチエイリアスは 1次で妥協している。</strong>25kHz サンプリングに対して fc 3.4kHz の 1次では 12.5kHz で −11dB。音声にはこの帯域の成分がほとんど無いので実用上問題ないが、気になるなら RC をもう1段足す。
- <strong>ADC は D1（GPIO1）。</strong>ESP32-C6 は GPIO0〜2 しか ADC に使えず、D0 はバッテリー監視で埋まっている（04章のピン割り当て）。
- <strong>A3E も保証認定で申請しておく。</strong>A2A だけで通すと、あとで電波型式の変更申請が必要になる。
