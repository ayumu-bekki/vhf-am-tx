# 144MHz ドレイン変調送信機

終段ドレイン変調（高レベル変調）による 1.5W の A2A 送信機。**本書はハードウェア — 回路・定数・部品・立ち上げ調整を扱う。**方式選定の経緯と却下した代案は別資料「設計判断記録」へ、MCU の中で起きること（ADC・信号処理・PWM・動作モード・送信シーケンス）は別資料「ファームウェア仕様書」へ分離した。境界は **MCU のピンから外が本書、内がファームウェア仕様書**。

Frequency

144 MHzSi5351A / PLL

Emission

A2Aトーン変調電信

Power

1.5 W搬送波 / ピーク 6 W

Modulation

Drain終段ドレイン変調

Battery

12.8 V4S LiFePO4 / 約 0.7 A

## 01全体ブロック図

RF 系統（上段）は入口から出口まで振幅が一定で、飽和させて構わない。音声が入るのは終段のドレイン電源だけで、ゲート側には一切触れない。ドライバは 2SC4703 の Vcbo=25V を守るため 8V で動かす（12V だと C級のピーク電圧が 24V に達して余裕がない）。

## 02なぜこれが AM になるのか

変調器は終段の電源そのものを音声波形で揺らす。無変調時 3.6V で 1.5W、ピーク 7.2V で 6W。ピーク時の 6W は変調器が供給しているので、音声側にも約 1.5W のパワーアンプが必要になる — これが「高レベル変調」と呼ばれる理由。

## 03変調器（M3）の回路図

オペアンプが負帰還で 2SK4017 のソース電圧を MCU の波形に追従させる、単なるリニアレギュレータ。違うのは基準電圧が音声波形で動くことだけ。

M2 が渡す 700Hz 正弦波（1.125V 中心）を基準として、ソースフォロワの出力を制御する。帰還は出力を 22k/10k で 1/3.2 に分圧して −入力へ（**ゲイン 3.2 倍**）。出力 3.6V のとき帰還ノードは 1.125V になるので、MCU 側は 1.125V を中心に振ればよい。出力側にクランプ用ツェナーは置かない。**ソースフォロワは +8V レールを超えられないので、ドレイン電圧の上限は構造的に 8V に決まっている**（下記）。

出力クランプ用ツェナーは置かない

- ソースフォロワの出力は **+8V レールを超えられない**。オペアンプが振り切れても、Q2 が短絡故障しても、ドレイン直流電圧の上限は 8V。設計ピーク 7.2V に対して 11% しか上がらず、**上限はレールがすでに決めている**。
- ここに 7.5V のツェナーを置くと、レールより 0.5V 低いところでクランプしようとすることになる。2SK4017 の Rds(on) は 0.1Ω 程度なので無負荷時に数 A が流れ込み、どんな定格のツェナーも焼ける。しかも導通するのは「ドライブ無し」＝終段に電流が流れず無害な場面だけで、**危険なときには働かない**。
- レールより上（9.1V など）に置けば安全だが、その場合に吸うのは L8 のフライバック `½LI² = 0.53µJ` だけ。しかも変調経路は音声帯域なので `di/dt` が小さく、実際に発生するのは `0.47µH × 1.5A/100µs = 7mV` 程度。**働く場面が存在しない。**
- ドレインが負に振れた場合は LDMOS のボディダイオードが −0.7V でクランプする。外付けは要らない。

では何が保険になるか

- **ファームウェアのデューティ上限。**運用範囲の上端 0.652、どんな場合も超えない絶対上限 0.730（04章）。搬送波レベルも変調度も数値で決まる設計なので、ここで縛るのが筋。
- **ヒートシンクを「8V 張り付きでも壊れない」寸法にする。**8V 連続では終段の損失が約 6.3W に達する（通常運用は 1W 未満。v000 の実測から換算）。**10°C/W 以下**の放熱にしておけば温度上昇 63°C で収まり、故障しても壊れない。通常運用では 10°C 程度しか上がらない。

### 2SK4017 の引き出しと放熱

2SK4017 は基板に載せず、**ケースの側板に取り付けてリード線で基板とつなぐ**。基板側 **J6** と FET 側 **J7**（どちらも 4ピン）の間を、4本より合わせた線で結ぶ。

| ピン | 基板側 J6 | FET 側 J7 | 線 |
| --- | --- | --- | --- |
| 1 | +8V | D（C5 の片側） | AWG22〜20。最大 1.5A |
| 2 | オペアンプ出力 | R9 470Ω → G | 細線で可 |
| 3 | GND | C5 の GND 側 | 細線で可 |
| 4 | Mod（C8・R8・TP2） | S | AWG22〜20。最大 1.5A |

ソースフォロワを配線で伸ばすときの約束

- **R9（470Ω）はゲートの足に直付け。**基板側に残して長い線でゲートへ行くと、線のインダクタンスとゲート容量で VHF の寄生発振を起こしやすい。
- **C5（0.1µF）を FET の足元で D–GND。**GND はケースではなく J7 の pin3（4本目の線）に取る。アルマイトの側板は本体と導通していないことがある。
- **帰還（R8）と C8 は基板側の Mod ノード。**線の抵抗による電圧降下（1.5A で数十 mV）もループが補正する。線のインダクタンスはループに入るが、高域は C6 でオペアンプ出力から帰還しているので影響は小さい。
- **4本をより合わせて 10cm 以内（できれば 5cm）。**RF 基板とアンテナコネクタの近くを通さない。
- 基板側 J6 の pin3 は R5 やオペアンプの GND ではなく **8V 電源側の GND** に寄せる。J6 は 8V レールの出力コンデンサの近くに置く。

### 放熱の見積もり

損失は `(8V − ドレイン電圧) × 電流`。終段を 3.57V ÷ 0.65A ≒ 5.5Ω の抵抗とみなすと、**ドレイン 4V（レールの半分）で最大**になり、搬送波はそのすぐ近くにいる。**連続搬送波が最も厳しい条件**で、余裕を見て **3.5W** で設計する。

| 状態 | 2SK4017 | 終段 Q4（参考） |
| --- | --- | --- |
| 搬送波（3.6V） | 約 2.9W | 約 0.7W |
| 変調 82%（平均） | 約 2.1W | 約 0.9W |
| ドレイン 4V（最大点） | 約 2.9W | — |
| 基準が張り付いて 8V | ほぼ 0W | 約 6W（終段側が熱くなる） |

- **許される熱抵抗。**チャネル 110°C 以下・ケース内 40°C とすると全体で `(110 − 40) ÷ 3.5W = 20°C/W`。素子の 6.25°C/W（Pd 20W からの計算値、データシートで要確認）と接触面を引いて、**放熱器側は 12°C/W 以下**。
- **取り付け。**ケース側板（1mm）の内側に 2SK4017、**同じ位置の外側にヒートシンク**を当て、M3 ネジ1本で3枚を共締めする。グリスは2面とも。板厚方向の熱抵抗は 0.05°C/W 程度で無視でき、1mm 板で熱が横に広がらない問題はヒートシンクが受け持つ。**ヒートシンクはカタログ値 8°C/W 以下**（40×40mm・フィン高 20mm 前後が目安）、フィンは縦向き。放熱用両面テープは使わない。
- **絶縁は不要。**TO-220SIS（フルモールド）なのでネジもヒートシンクも GND 電位でよい。
- **確認。**連続 30分で、ヒートシンクの根元（素子の真裏）が **60°C 以下**なら合格（チャネルはおよそ +25°C 以内）。

## 04M2 トーン生成と平滑フィルタ

MCU が PWM で 700Hz の正弦波を合成し、M2 はその PWM を平らにするだけ。落とすべき高調波が最初から無いので、**抵抗2本とコンデンサ2個**で足りる。オペアンプも半固定抵抗も要らない。インピーダンスは低いほうが送信機の中で有利なので 1kΩ を使う。

直流も通すので、PWM のデューティ平均がそのまま搬送波レベル（M3 の基準電圧）になる。交流結合が無いぶん、キーイング時の過渡もリセット後のふらつきも起きない。

### PWM に求める仕様

M2 の出力は `3.3V × デューティ × |H|`、M3 が 1/3.2 分圧で帰還しているので **ドレイン電圧 = M2 出力 × 3.2**。ここから、回路側が MCU に要求する値が決まる。**これが回路とファームウェアの境界**で、以下はすべて回路の定数から導いた値。

| 項目 | 値 | 導出 |
| --- | --- | --- |
| PWM 周波数 | 250 kHz | M2 で −74.7dB 減衰する（下表）。これより低いと残留が増える |
| デューティ分解能 | 8 bit 以上 | 1LSB がドレイン 41mV ＝ 搬送波 3.6V の 1.1% |
| デューティ更新レート | 25 kHz | 折返しが 24.3kHz に出て M2 で −34.8dB 落ちる（下表） |
| 搬送波点のデューティ | 0.341 | 1.125V ÷ 3.3V（レジスタ 87）。ドレイン 3.6V ＝ 出力 1.5W |
| 変調度 80%・700Hz の振幅 | ±0.311 | 0.90V ÷ (3.3V × 0.877)。700Hz での `\|H\|` 込み |
| A2A の運用範囲 | 0.030 〜 0.652 | 上の2つから決まる |
| **デューティの絶対上限** | **0.730** | ソースフォロワの上限 `8V − 1.5A × 0.1Ω = 7.85V` は `7.85 ÷ 3.2 ÷ 3.3 = 0.743`。そこから余裕を取ってレジスタ **187**（ドレイン 7.71V）。ファームウェアはここを超えてはならない |
| フルスケールで取れる振幅 | 1.45 Vpk | 必要な 0.90Vpk の 1.6 倍。余裕あり |

**搬送波レベルも変調度もソフトウェアの数値で決まる**ので、半固定抵抗が要らない。実測して定数を書き換えるだけで追い込める。LEDC の設定・デューティ写像・エンベロープ整形・動作モードといった実装側の規定は、**別資料のファームウェア仕様書**にまとめた。

### 残留スプリアス

| 成分 | 周波数 | RC 減衰 | 出力 |
| --- | --- | --- | --- |
| 700Hz トーン | 700 Hz | −1.14 dB | **0.90 Vpk** |

トーンは合成された正弦波なので、方形波方式で問題になった 3倍波（2.1kHz）は原理的に出ない。残るのは PWM と更新レートの残留だけで、どちらも −64dBc 以下に収まる。

### 送信の開始と停止：順序は回路が決めている

この構成には **2つのスイッチ**しかない。`Si5351A の CLK0`（搬送波そのもの）と、`PWM のデューティ`（ドレイン電圧＝出力電力）。この2つを動かす順序は回路の都合で決まっていて、選択の余地がない。

- **開始は CLK0 が先、デューティが後。**CLK0 が来ていてもドレインが 0V なら電波は出ないので、この間に PLL のロックを待てる。
- **停止はデューティが先、CLK0 が後。**デューティを落としてから 10ms ほど待ち、ドレイン電圧が 0 付近まで下がってから CLK0 を切る。

順序を逆にしてはいけない理由

- **クリックが出る。**搬送波を先に切ると、1.5W の出力を瞬間的にゼロにすることになる。ステップ応答の側波帯が数十 kHz にわたって広がる。ドレインを先に落としておけば、切る瞬間の電力がほぼゼロなので何も起きない。
- **Mod ノードが下がらなくなる。**ソースフォロワは電流を流し出せても**吸い込めない**。ドレイン電圧が下がるのは終段が電流を引くからで、ドライブを先に切ると終段が電流を引かなくなり、Mod ノードは 3.6V のまま浮いたまま残る。

具体的な手順（デューティを落とす時間、待ち時間、状態機械）はファームウェア仕様書の規定による。なお A2A のキーイングでは**搬送波を切らずトーンだけを断続させる**ので、この停止手順が走るのは運用の終わりだけになる（12章「運用の注意」）。

### ドレインを 0V にするだけでは止まりきらない

終段のドレインを 0V にしても、ドライブが生きている限り **Crss（ゲート-ドレイン間容量）経由で漏れる**。ゲートの RF は約 2.7Vpk なので、Crss を 1〜2pF とすると

`I = ω·Crss·Vg = 2π × 145MHz × 1pF × 2.7V = 2.5mA` → 負荷 3.5Ω で 8.6mVpk → **約 10〜40µW（−45〜−52dBc）**。

1.5W に対しては小さいが、近くの局には確実に聞こえる。**完全に止めるには CLK0 を切る必要がある**。逆に言えば、A2A のキーイングで搬送波を出したままにする方式なら、この漏れは問題にならない。

搬送波の停止はファームウェアに依存する

- AE-Si5351A-B には **OEB ピンが出ていない**（8ピンは VDDO / SCL / SDA / GND / CLK0-2 / VDD）。搬送波を止める手段は I2C レジスタ経由しかない。
- したがって **MCU がハングすると送信し続ける**。ウォッチドッグを必ず入れ、リセット時は GPIO が Hi-Z になってデューティ 0＝出力ゼロに落ちることを利用する（下の「電源投入時とリセット時」）。
- 確実な最終手段は **SW_Power（主電源）**。運用中に手が届く位置に置く。
- ハードウェアの送信禁止を追加するなら、**ドライバのベースバイアス（R31 620Ω）を GPIO で GND へ短絡する**のが一番安い。2SC4703 が止まり、終段へのドライブが消える。

電源投入時とリセット時

- PWM が動き出す前、GPIO は Hi-Z か Low になる。M2 は直流を通すので、そのまま M3 の基準が 0V になり、**送信は止まる**（安全側）。
- 逆に GPIO が High に張り付くと基準が 3.3V になり、M3 が振り切れて終段に 8V がかかる。ただし 8V レールが上限なのでそれ以上は上がらず、しかもその状態では終段に電流が流れないので破壊には至らない。**本来の保険はファームウェア側のデューティ上限**（運用 0.652 / 絶対 0.730）で、これを超えないようにコードで縛る。
- 念のため M2 の入口に **100kΩ のプルダウン**を入れておくと、Hi-Z のときに確実に 0V へ落ちる。

### MCU のピン割り当て

**ADC が使えるのは GPIO0〜GPIO2（D0〜D2）だけ**という ESP32-C6 の制約があるので、アナログ2系統はここに固定される。PWM は GPIO マトリクス経由なので任意のピンに出せる。

押しボタンの働きはモードによって変わる（音声送信 / ARDF送信 / 周波数切替 / コールサイン編集 / ARDF識別信号）。**モード構成と各ボタンの具体的な動作はファームウェア仕様書**に規定した。主電源は番号を振らず **SW_Power**（09章）とし、押しボタンだけを 0 から連番にしてある。

PWM を出すピンの選び方

- PWM の出力はそのまま M2 を通って M3 の基準電圧になり、**ドレイン電圧 = その電圧 × 3.2** で終段に直結している。したがって**起動中にそのピンがどう振る舞うかが、そのままドレイン電圧になる**。
- **UART0 の TX（GPIO16 / D6）を使ってはいけない。**ROM ブートローダが起動時にログを出力し、しかも UART のアイドルは High なので、起動中ずっと 3.3V に張り付く。ドレインが 8V レールまで振り切れる。ROM の出力は eFuse で制御されるためソフトウェア設定では止められない。
- UART0 の RX（GPIO17 / D7）は入力として初期化されるだけだが、内蔵プルアップが有効になると外部 100kΩ プルダウンとの分圧で 2.3V 程度が乗る。
- **実際に使っているのは GPIO2（D2）。**ストラッピングピンではなく（ESP32-C6 のストラッピングは GPIO4 / 5 / 8 / 9 / 15）、ブート時に UART などの機能も出ない。ただし ADC1 CH2 と LP_GPIO2 を兼ねていて、**リセット直後の内部プルアップ／プルダウンの状態はデータシートで確認できていない**。内部プルアップが効いていると、外部 100kΩ との分圧で M3 の基準が持ち上がる。**電源投入とリセットのときに TP2（変調器出力）が 0V のままであることを、実機で確かめること**（PCB の立ち上げ手順に入れる）。当初の設計は GPIO21（D3）だった。
- いずれの場合も CLK0 が停止していて終段にドライブが無いため電流が流れず、実害には至らない（上記「電源投入時とリセット時」）。とはいえ振れないピンを選ぶに越したことはない。

## 05キャリア整形フィルタとパッド

47nH と 22pF だけで構成する定数k形 LPF。方形波で最大の 3倍波（−9.5dBc）に −42dB を当てるのが主な役割。挿入損失は 145MHz で −0.26dB。

フィルタ本体は 47nH と 22pF だけ。特性インピーダンス `√(L/C) = 46.2Ω` が 50Ω にほぼ一致していて、値の選び方がうまい。**直流阻止の 1000pF はパッドより前**に置く（下記参照）。パッドは Si5351A の出力レベル調整と、フィルタから見た信号源インピーダンスの安定化を兼ねる。

200〜290MHz が「なだらか」なのは、この帯域がまだ通過域の中だから。カーブの途中の盛り上がりは 270MHz 付近で整合が戻る点（リターンロス −18dB）で、そこだけ素通りしてしまう。本格的に落ち始めるのは 310MHz 以降で、3倍波の 435MHz はその急斜面の上に乗っている。グラフ上をなぞると任意の周波数の減衰量が読める。

| C20 / C21 / C22 | 22 pF | C0G(NP0) 50V |

### 直流阻止コンデンサ

1000pF（1608、C0G）。整合素子ではなく単なる直流阻止なので、ESL 込みの 145MHz でのリアクタンスが 0.55Ω＝50Ω の 1.1% と十分小さいことが条件。470pF 以上で特性は飽和するので 1000pF で余裕がある。

置く順序：直流阻止 → パッド

- Si5351A の出力は 0〜3.3V を振る CMOS ドライバなので、出力ピンには **直流平均 1.65V** が乗っている。
- ここにパッドを直結すると、並列 300Ω に **5.5mA の直流**が流れる。8mA ドライブ設定に対して 69% で、ドライブ能力を大きく食われるうえ High レベルも下がる。
- 1000pF をパッドの**前**に置けば、パッドは交流だけを見るのでこの問題が起きない（ADR-006）。

### パッド

Si5351A の出力は CMOS ドライバなので、出力インピーダンスが 50Ω ぴったりではない。定数k形フィルタは終端インピーダンスに敏感なので、パッドで 50Ω を保証しておく効果が大きい。あわせて、フィルタが反射した高調波を吸収して Si5351A の出力段に戻さない役目もある。

| 減衰量 | π型（直列 / 並列×2） | T型（直列×2 / 並列） |
| --- | --- | --- |
| 2 dB | 12Ω / 430Ω | 5.6Ω / 220Ω |
| **3 dB** | **18Ω / 300Ω** | 8.2Ω / 150Ω |
| 4 dB | 24Ω / 220Ω | 11Ω / 100Ω |
| 6 dB | 36Ω / 150Ω | 16Ω / 68Ω |
| 10 dB | 75Ω / 100Ω | 27Ω / 36Ω |

まずは **3dB**（π型：直列 18Ω / 並列 300Ω×2）で組み、ドライブが足りなければ抵抗を差し替えて減らす。0dB（直結）まで戻せるパターンにしておく。

### 使用するモジュールと周波数の決め方

秋月 **AE-Si5351A-B**。ピン配置は `1=VDDO / 2=SCL / 3=SDA / 4=GND / 5=CLK0 / 6=CLK1 / 7=CLK2 / 8=VDD`。基準は **25MHz**（FA-128）。**オンボードレギュレータもプルアップも載っていない**ので、VDD / VDDO には 3.3V を直接与え、I2C のプルアップ（10kΩ×2）は基板側で用意する。VDD の推奨は 2.5〜3.3V なので、3端子の出力誤差込みで 3.4V を超えないこと。CLK1 / CLK2 は未使用なのでレジスタで停止させておく。

周波数の設定で決まるものが2つある。どちらも**フィルタでは消せない**ので、ファームウェア側で押さえる。

- **搬送波のすぐ近くのスプリアス。**PLL が分数分周だと搬送波の近傍にスプリアスが出て、入口の LPF も出口の LPF も素通りする。VCO（PLL）と MultiSynth の**両方を整数**にすると最小になる。25MHz 基準で 144MHz 帯（PLL 864〜876MHz）に入る整数 PLL は **875MHz（×35）だけ**で、÷6 の **145.833MHz** が両方整数になる唯一の点。
- **2倍波。**上のフィルタは 290MHz で −7dB しか取れないが、**MultiSynth を偶数整数（÷6）にすれば出力デューティがほぼ 50% になり、2倍波は原理的にほとんど出ない**。
- したがって、145.833MHz 以外の周波数でも **MultiSynth は偶数整数 6 に固定し（PLL = 出力 × 6 = 864〜876MHz）、PLL 側を小数分周にする**。デューティ 50% が保証され、分数分周のスプリアスもこの条件で最小になる。運用周波数を決めるときは、この条件とバンドプランを突き合わせる。

## 06ドライバ段（2SC4703）

+4.7dBm を +20dBm（100mW）まで持ち上げる。必要利得は 15.3dB。ドレイン変調のチェーンは定振幅なので飽和させて構わず、むしろ**軽く圧縮させておくと Si5351A の出力ばらつきが終段に伝わらない**。

バイアス分圧をベースへ直結している。ベースから見た分圧の抵抗は 514Ω で、入力インピーダンス 15Ω に対する損失は 2.9%（0.13dB）しかないので、バイアス用の RFC は省ける。10Ω のベース直列抵抗は安定化と、入力整合回路とベースの絶縁を兼ねる。**破線の C39 は実装しない** — コレクタ節点の浮遊容量と Cob が並列 C の役を果たす。

### 実装と調整

- **エミッタの接地が最優先。**22Ω とバイパス 2200pF は 2SC4703 の直下に置き、グランドまで最短で。ここのインダクタンスがそのまま負帰還になって利得と安定度を削る。
- **入力側の L7 は必ず可変に。**2SC4703 の 144MHz での S パラメータが公開されていないため、Zin は推定値（約 15 − j25Ω）。終段の入力整合（07章）と同じ理由で、実測で追い込む前提。
- **出力側は L6 だけで合わせる。**コレクタ負荷はロードラインで決まる実数（281Ω）なので、11章の抵抗置換法（270Ω）で素子なしに追い込める。ただし **281Ω → 50Ω の L 網に必要な並列 C は 8.5pF と小さく、パッドや配線の浮遊容量だけで大半が埋まる**。v000 基板では浮遊が 6.63pF あり、トリマ C39 は最小容量に回しても行き過ぎたので実装しないことにした（ADR-020）。基板を作り直したら、まず C39 を外した状態で浮遊を測ってから判断する（11章 手順5）。
- **圧縮させて使う。**利得は 18〜22dB 見込めるので、必要な 15.3dB に対して 3〜6dB の圧縮がかかる。これが終段へのドライブを安定させる。入力側にパッドを追加する場合（05章）もこの圧縮が効いて出力が動きにくい。
- **直流阻止はドライバ側に置く。**1000pF が L6 の前でも終段の整合回路の入口でも、RF 的には等価（144MHz で 1.1Ω）。ただしドライバ側に置けば、段間の配線が直流 0V になる。段間で切って電力計を当てられるし、この配線が半田ブリッジでグランドに落ちても 8V レールを短絡しない。**直流阻止は、直流が乗っている側の段に持たせる。**
- **発振チェック。**fT が 6GHz あるので UHF での発振に注意。ドライブを切った状態、バイアスを振った状態の両方で SDR に何も出ないことを確認する。怪しければベース直列抵抗を 10Ω → 22Ω に増やす（利得は 1〜2dB 落ちるが余裕がある）。

## 07終段の整合回路

**出力はロードライン計算**（3.5Ω → 50Ω）、**入力はデータシートの実測 Zs**（175MHz・Idq=500mA の値を代用）で定数を出し、どちらも実測で追い込む。出力側は抵抗置換法で素子なしに合わせられるが、入力側は C級のゲートが小信号では導通しないため、**大信号を入れてから決める**（下記）。

入力側は 50Ω をゲート（データシート実測ベースで Zs≈14+j9Ω、ADR-016）へ、出力側はドレインが必要とする 3.5Ω 前後（同ZL≈5−j3Ω）を 50Ω へ変換する。ドレインへの給電チョーク（0.47µH 空芯）は 145MHz で 471Ω あり、3.5Ω の負荷に対して 0.7% しか影響しない。

### 出力：ロードラインから決まる

C級増幅段が必要とする負荷抵抗は `R = (Vd − Vknee)² / (2·Pout)`。

| 動作点 | Vd | Pout | 必要な負荷 |
| --- | --- | --- | --- |
| 無変調（搬送波） | 3.6 V | 1.5 W | 3.0 Ω |
| 変調ピーク | 7.2 V | 6.0 W | 3.6 Ω |

出力が Vd² に比例して動くので、**搬送波時とピーク時で最適負荷がほとんど同じ**になる。ドレイン変調が素直に働くのはこのためで、どちらかに合わせれば両方で最適になる。設計値は **3.5Ω** とした。

| 素子 | 値 | 備考 |
| --- | --- | --- |
| L10 | 14 nH | 1.3 Arms 流れる。空芯・φ3mm 心棒に 2T（13章）。**可変**。実測で追い込んだ値はリード込みで **14.1nH**（16章） |
| C50（DC ブロック） | 0.01 µF | C0G 50V / 3216。0.01µF は ESL と自己共振して 145MHz では容量ではなく **約 1Ω の誘導性**になるが、L10 に直列に足されるだけなので伸縮で吸収できる |
| C52 / C53（並列 C） | 合計 約 83 pF | **56pF 固定 + 30pF トリマ**（浮遊込みで約 62〜91pF）。3.3Ω → 50Ω に必要な値は 82.6pF で、実測もそこに落ちた。Q4 を載せると Coss の影響で 86pF 前後へ動く見込み（ADR-021） |
| ロードQ | 3.6 | 帯域 40MHz。2倍波も 6〜10dB 落ちる |

Coss は 40〜250pF のどこにあっても L10 は 13〜14.5nH に収まる（ドレイン側が 3.5Ω と低インピーダンスなので摂動が小さい）。**出力整合は計算値で作ってよい。**ただしドレイン変調では Vd が動くたびに Coss も変化するので、整合は搬送波点（3.6V）で最適化する。

### 入力：こちらは敏感なので可変にする

データシートの実測 Zs（スミスチャート）で 175MHz — 本機の 144MHz に最も近い実測点 — は **Zs = 13.90 + j9.38Ω**。これを L 網（直列 L → 並列 C → 50Ω）で解くと、直列 L は **29〜35nH**、並列 C は **29〜36pF**。**L14 = 33nH**（φ3mm に 4回、13章）と **C60 15pF 固定 ＋ C61 30pF トリマ**（合計の可動域 約 20〜45pF）がこの範囲に対応する。導出は ADR-016、L14 の心棒は ADR-018、並列 C の構成は ADR-019 を参照。

ただしこの Zs は 175MHz・Idq=500mA（AB級寄り）というデータシートの測定条件での値で、本機の 144MHz・Idq≈0（C級）とは条件が異なる。**L14 は必ず空芯の可変コイルにして実測で追い込む**こと。

小信号の S11 では入力整合を追い込めない（実測で判明）

- Idq ≈ 0 にバイアスした C級の終段は、NanoVNA の −13dBm 程度ではゲートが閾値に全く届かず、**完全にオフのまま**。見えているのは Ciss とゲート配線抵抗だけになる。
- v000 基板の実測では J1 から見て **3.8 + j15.9Ω（リターンロス −1.2dB）**。逆算するとゲート単体は **約 1.7 − j32Ω（Ciss 約 34pF）**で、実部がデータシート値 13.9Ω の 1/8 しかない。
- 実部 1.7Ω を 50Ω に変換するには並列 C が **約 118pF** 要り、C60 + C61（最大 45pF 程度）では原理的に届かない。L14 はすでにほぼ最適（必要 46nH に対し密着巻き 48nH）で、コイルをどう伸縮しても −1.4dB までしか改善しない。
- **並列 C を 118pF に増やしてはいけない。**大信号ではゲートが導通して実部が上がり、必要な C は設計値の 35pF 付近に戻る。小信号に合わせると大信号で外れる。
- したがって入力整合（L14 / C61）は **大信号を入れて「同じ出力を得るのに必要なドライブが最小になる点」で決める**（11章 手順6、ADR-023）。小信号の S11 は発振していないことの確認にだけ使う。

### ゲートバイアス回路

ドレイン変調では、出力が `Vd²` に比例することが前提になる。そのためには終段が**飽和した C級**で動いている必要があり、無信号時のドレイン電流 Idq はほぼ 0 でなければならない。Idq が残っていると変調の谷でキャリアが抜けきらず、下側変調度が頭打ちになる。したがってゲートバイアスは「しきい値の少し下」に置く。

LDMOS の Vgs(th) はロットで 1.5〜2.5V ばらつくので、**固定値では決め打ちできない**。半固定抵抗で 0〜3.2V を可変にして、実測で追い込む。逆に Idq ≈ 0 で使う限り熱暴走の心配がないので、AB級リニアアンプのようなダイオードやサーミスタによる温度補償は不要。

分圧の内部抵抗 6.0kΩ が 10µF と組んで `fc = 2.7Hz` のローパスになる。8V レールは変調で 0〜1.5A に振れるが、その 700Hz 成分はここで 48dB 落ちるので、ゲート電位は動かない。R34 220kΩ は半固定のワイパが浮いたときにゲートを 0V へ落とすための保険。1000pF はチョークの冷側を RF 的に接地する。

| R35 + L9 | 100Ω + 1µH（巻線） | B82498F1102J000（SRF 440MHz）で 145MHz に約 1.0kΩ。直流電流は流れないので定格は不問。R35 は低域でチョークの Q を潰す |

半固定抵抗は**ポテンショメータ結線（3端子とも使う）**にする。可変抵抗結線（ワイパと片端を短絡）にすると、ワイパが浮いたときに全抵抗が残って中途半端な電圧がゲートに出る。3端子結線ならワイパ断線でノードが開放になり、R34 が 0V へ引いてくれる。

ドレイン給電は **J13**（2ピンのジャンパ。pin1 = 変調器出力 Mod、pin2 → C43 → L8 → ドレイン）。運用時は短絡し、Idq はここに電流計を直列に入れて読む。8V はゲートバイアス分圧（R33 / RV1、0.32mA）が使うだけ。**v000 の Final 基板では J4 がドレイン給電、J5 が 8V 入力**だった（11章・16章の記録はその番号）。

### 安定度と実装

- **ソース接地が最優先。**SOT-89 のタブ直下にサーマルビアを兼ねたビアを多数打ち、太く短くグランドへ。ソースのインダクタンスは利得と安定度を直接殺します。ここが一番の勘所です。
- **低周波発振の対策。**LDMOS は低い周波数ほど利得が高く、バイアス回路の共振で発振します。ゲートバイアスは `1µH + 100Ω` を直列に入れて供給します。バイアス源が 6kΩ の分圧なので、これ自体がダンピング抵抗として働きます（別途 10Ω を入れる必要はありません）。
- **ゲートに直列抵抗は最後の手段。**2〜4.7Ω を入れると確実に安定しますが、ゲート抵抗が 2Ω しかないので利得を 3dB 近く失います。まずバイアス回路のダンピングで対処を。
- **チョークに積層（多層）チップインダクタを使わない。**積層品はフェライトを焼き固めた構造で、1µH で SRF 50MHz、2.2µH で 30MHz 程度しかない。145MHz では共振点のはるか上、しかも損失が大きいので**抵抗として振る舞う**。ドライバのコレクタに使うと 145MHz でのインピーダンスが 90Ω しかなく、負荷 281Ω に対して**出力の 63% を熱にする**。ゲートバイアス側でもドライブを 15%（−0.7dB）食われる。**巻線（ワイヤワウンド）型を指定すること** — 同じ 1µH でも SRF 200MHz、145MHz で 1.9kΩ、損失 0.1% に収まる。
- **素性の分からないチップインダクタは実測してから使う。**NanoVNA の2ポート間に直列に挟んで S21 を見る。直列インピーダンスは `|Z| = 100 × (1/|S21| − 1)` なので、145MHz で **巻線型なら −26dB 前後、積層型なら −7dB 前後**と桁違いに差が出る。LC メーターは 100kHz で測るためどちらも同じ値を示し、区別できない。
- **チョークをフェライトビーズで代用しない。**ビーズは 145MHz でも 150Ω 程度の*抵抗*で、直流電流で値が崩れる。空芯 0.47µH の 471Ω（純リアクタンス）とは別物で、ドレインに使うと電力を食い、変調電流でインピーダンスが揺れて包絡線が歪む。**ドレイン給電は空芯で自作する**（13章）。市販品を使うなら Isat 2A 以上 / DCR 0.1Ω 以下 / SRF 300MHz 以上が条件だが、この3つを同時に満たすチップ品は入手しにくい。ビーズは電源ラインの高周波阻止に使う部品。
- **R36 を外したまま送信しない。**R36 は LPF を単体で掃引するための切り離し点（11章）。外すと終段が無負荷になり、ドレイン電圧が跳ね上がって素子を壊す。

### 追い込みの手順

終段の整合とゲートバイアスの追い込みは、全体の立ち上げの中に位置づけて **11章**にまとめた。出力側（L10 / C53）を抵抗置換法で先に決め、入力側（L14 / C61）は大信号で決める。その後 2〜3 往復させる。v000 基板での実測値は **16章**。

## 08出力 LPF の設計

7次チェビシェフ（0.1dB リップル、fc=160MHz）。C級終段の2倍波 −15dBc を −60dBc 以下に落とすため、288MHz で 50dB の減衰を確保する。

7次チェビシェフ、CLCLCLC 構成。コンデンサは **22pF ひとつだけ**で構成できる — 中央の2箇所は 22pF を2個並列（C55/C56、C57/C58）にして 44pF とする。部品の種類が減るうえ、電流の大きい中央のコンデンサを2個で分担できる。

コイルQ=150 として計算した特性。144〜146MHz（縦の帯）と 288MHz の間には 2倍しか離れていないので、この急峻さを出すには7次が要る。グラフ上をなぞると任意の周波数の減衰量が読める。**破線より下は理論値**で、実基板ではここまで落ちない。v000 基板では 289MHz が −53dB と計算を上回った一方、433MHz は −41dB で頭打ちになった（下表）。

### 作るときの注意

- **コイルは隣同士の軸を直交させ、直径の2倍以上離す。**一般的な作法なので守っておく。v000 基板は L12 だけ 90° 回したレイアウトになっている。
- **ただし v000 の 433MHz の頭打ち（−41dB）はコイル間の結合が原因ではなかった。**L13 を基板に垂直に立てても、L12 を垂直に立てても 433MHz はほぼ動かなかった。一方で L12 の片脚を浮かせてフィルタの鎖を切ると −56dB まで下がり、ケーブルを基板から外すと −65dB になる。つまり**信号はフィルタの素子を通って漏れている**。有力な候補はシャント C のグランド帰路のインダクタンス（パッド〜ビア）だが未検証。v001 でグランド処理を見直す課題として残す（ADR-022）。
- **入出力間の距離とシールド。**入口と出口を基板の対角に配置し、可能なら仕切り板を1枚入れる。
- **コンデンサは C0G(NP0) 必須。**X7R は損失と電圧係数で使えません。中央の2箇所には 0.9Arms、33Vp がかかるので、100V 品を 2個並列（C55/C56、C57/C58）にします。
- **コイルは伸縮で微調整。**巻き数を変えず、長さを±1mm 変えると 10% ほど動きます。インダクタンスが ±10% ずれても挿入損失 0.4dB / リターンロス 16dB 程度に収まるので、神経質にならなくて大丈夫です。
- **チップインダクタでも可。**68nH / 82nH で代用できますが、Q が 60 程度に落ちるため挿入損失が 0.7dB（約15%の電力損）に増えます。空芯のほうが有利です。

## 09電源系統

8V は必ずスイッチングで作る。3端子だと `(12.8−8)×0.8A = 3.8W` を捨てることになり、MOSFET の 3.5W と合わせてヒートシンクが倍必要になる。降圧DC-DC のリプルは、シリーズパス変調器そのものがリニアレギュレータとして働くため、帰還ループが自動的に潰してくれる。5V レールを持たないこと、Si5351A を MCU のレールに相乗りさせないことの理由は下の「電源系統の注意」。

### 電源系統の注意

- **Si5351A は 3.3V 品。**VDD の絶対最大が 3.60V。レギュレータを載せたブレークアウト基板でない限り、3.3V 以外を入れてはいけない。使うモジュールにレギュレータが載っているかは実装前に必ず確認する。
- **LCD は +3.3VA から取る。**AQM0802A（ST7032）は液晶バイアス用のチャージポンプを内蔵していて常時スイッチングしているので、周波数基準の +3.3VB に相乗りさせない。消費は 0.4mA なので MCU レールへの影響は無視できる。**I2C のプルアップ（R2 / R3）は +3.3VA に取る**（2026-10-15 に +3.3VB から変更）。Si5351A の電源に通信のたびの電流が流れず、8V が無い状態（USB だけでの書き込み・デバッグ）でも ESP32 と LCD が通信できる。Si5351A の SCL / SDA が自分の VDD より少し高い "H" を受けることになるので、絶対最大定格（3.6V までのはず）をデータシートで確認しておく。
- **FB2 は「電源を綺麗にする」ための部品ではない。**フェライトビーズは 10MHz 以下では素通しなので、LDO の出力ノイズには何も効かない。効くのは **145MHz そのもの**で、役割は2つある。\
  ① **Si5351A の出力電流を閉じ込める。**CLK0 は 8mA の CMOS ドライバで、その電流は VDDO から供給される。ビーズが無いと 145MHz の電流が 3.3VB の配線（20nH ≒ 18Ω）を通って電源部まで戻り、そこから放射する。**これは出力 LPF の外側の経路なので、LPF では消せない。**ビーズ（145MHz で 150〜200Ω）を入れると漏れは `18/150` ≒ **17dB** 減る。\
  ② **終段の 1.5W を電源配線が拾うのを防ぐ。**拾った RF が VDD に乗ると出力にスプリアスが出る。モジュールがピンヘッダ実装で電源経路にインダクタンスがあるぶん、なおさら効く。
- **FB2 を抵抗で代用しない。**10Ω を入れると 38mA で 0.38V 落ちて 2.9V になり、Si5351A の動作範囲を割る。**直流では 0Ω、145MHz では 150Ω** という性質そのものが必要。
- **Si5351A の 3.3V は MCU と共有しない。**ESP32C6 は WiFi/BLE で数百 mA のパルス電流を引く。周波数基準を MCU と同じ降圧コンバータの出力にぶら下げると、その負荷変動とスイッチングリプルが LDO の PSRR を通らずそのまま VDD に乗る。**8V レールから 82Ω を介して専用 LDO** を立て、直近に 0.1µF + 10µF を置く。
- **5V レールは作らない。**XIAO ESP32C6 は 3V3 ピンから直接給電できるので、5V を経由して内蔵レギュレータで落とす必要がない。BP5293-33 が 3.3V を出して MCU 専用とする。
- **Si5351A の LDO を 8V から取っても問題ない理由。**8V レールは変調で 0〜1.5A に振れるが、レール上のリプルは 100mV 程度で、LDO の PSRR（1kHz で 50dB 前後）と 82Ω + 10µF の前置フィルタ（fc 194Hz）を通ると VDD では 1mV を切る。抵抗を入れることで LDO の入出力差が 1.7V に落ち、SOT-23 パッケージの損失も 179mW → 65mW になる。
- **8V レールのピーク時の落ち込みを実測する。**変調ピークで出力 7.2V を出すには、パス MOSFET のドロップ（0.2V 程度）込みで 8V レールが 7.4V 以上を保つ必要がある。RT8250 は 3A 品なので電流は足りるが、1kHz の負荷変動に対する応答は出力コンデンサ次第。足りなければ 220〜470µF を追加するか、レールを 8.5V に上げる（MOSFET の損失は 3.5W → 3.9W）。
- **17.4V は必ず電池側から。**NJW4190M は倍電圧なので、8V レールから取ると最大 16V 弱にしかならず 17.4V を出せない。
- **バッテリー電圧は MCU で監視する。**100kΩ / 18kΩ の分圧（R4 / R7）で D0 の ADC へ入れる。常時 144µA 流れるが、3Ah に対して約 2400 時間ぶんなので許容範囲。**下限は 10.5V** — ここを割ると NJW4190M が 17.4V を出せず、降圧DC-DC が音を上げるより先に変調器のオペアンプが動作範囲を外れる。ファームウェア側で送信を禁止する。
- **送信ピークで 0.3〜0.5V は落ちる。**1.05A 引くので、電池の内部抵抗とケーブルぶんが落ちる。監視の判定を瞬時値で行うとキーイングのたびに送信が止まるので、平均値で判定すること。
- **過電流保護はポリスイッチ（PPTC）で足りる。**セル側の破局的な故障はパック内の BMS が見るので、基板側の保護に求められるのは「基板や配線が焼ける前に電流を切る」ことだけ。復帰型なので、運用中に落ちても予備を持ち歩かなくてよい。**保持電流 1.85A / 定格 30V 級**を選ぶ。直列抵抗 0.05〜0.15Ω は、ピーク 1.05A で 0.05〜0.16V の電圧降下にしかならない。
- **ポリスイッチは温度で保持電流が下がる。**周囲 60°C では 23°C 定格の 65〜70% しか流せない。終段の MOSFET が 3.5W を出す密閉筐体では実際に 50〜60°C になるので、`1.05A ÷ 0.65 = 1.6A` を下回らない品を選ぶ。1.0A や 1.35A 品では変調ピークで誤動作する。
- **3V3 ピンは内蔵レギュレータの出力でもある。**USB を挿したまま外部 3.3V を入れると、内蔵レギュレータと BP5293-33 が同じノードを取り合う。**BP5293-33 → 3V3 の間に 2ピンのジャンパ（J12）を入れて、書き込み時は外す**。BP5293-33 は出力固定 3.3V なので、RT8250 で使えた「出力を高めに設定してダイオードで落とす」手は使えない — ジャンパで確実に切り離すのが唯一の方法（ADR-014）。
- **USB 接続中は Si5351A も終段も無電圧になる。**この構成では書き込み時に主電源を切るので、送信部が動かない状態でファームを焼くことになる。動作確認は主電源を入れ直してから行う。

## 11立ち上げと調整

段ごとに切り分けて進める。**順序を飛ばさないこと** — 変調器が暴れた状態で終段に給電すると一発で飛ぶ。

この章は v000 の2枚基板（Driver / Final）での手順

- **部品番号は 2026-10-15 に振り直した回路図に合わせてある**（14章「部品番号の新旧対応」）。
- 一方、**コネクタとテストポイント（Driver / Final の J1・J2、Final の J4・J5・TP1）は v000 の各基板の番号のまま**。新しい1枚基板には無い。読み替えは、Final の J4（ドレイン給電）→ **J13**（ジャンパ）、J5（8V）→ 基板内の +8V（部品は無い）、段間の SMA → **R28 / R37**（0Ω）、出力 SMA → **J14**、Final の TP1 → **TP7**。
- 新しい1枚基板での立ち上げ順は、プロジェクトの `claude/next-steps.md`。

現構成では RF 部が **Driver 基板**と **Final（＋LPF）基板**の2枚に分かれていて（12章）、段間の切り離しは **SMA の同軸を抜き差しするだけ**で済む。基板内に残る切り離し点は **R36**（終段出力整合と LPF の間の 0Ω）だけで、Final 基板の電源は **J4**（ドレイン）と **J5**（8V）から別々に入れる。

1枚基板にまとめたときの読み替え

- 将来 RF 部を1枚にまとめる段になったら、いま SMA コネクタが立っている位置が **0Ω チップ抵抗＋テストポイント**に置き換わる（12章）。Driver 基板の入力が **R28**（隣の GND が TP4）、Driver 出力〜Final 入力が **R37**（隣の GND が TP8）に対応する。
- 下の手順はそのまま使える。**「同軸を抜く」を「0Ω を外す」、「SMA に繋ぐ」を「テストポイントに当てる」と読み替える**だけで、測る場所も目標値も変わらない。

### 検波プローブ

RF 電力計は使わず、これで代用する。ダミーロードの両端に当てて、**包絡線の観測と出力電力の測定を1つで済ませる**。145MHz を直接オシロで見る必要がなくなるので、20MHz 帯域のオシロで足りる。

**D1 はダミーロードに直結する。間に直流阻止のコンデンサを入れてはいけない** — R1 が引く直流がダミーロードの 50Ω を通って戻ってくるのが前提で、コンデンサがあると帰り道が無くなり、出力は 0V のまま動かない（初版の図には 0.01µF が入っていた誤り。v000 で実際に 0V になった）。各基板の出力は C50 などで直流を切ってあるが、**使う前に出力 SMA の芯線が 0V であることをテスタで確認**する。時定数 `R1 × C2 = 10µs`。145MHz（6.9ns）は完全に平滑され、700Hz（1.43ms）の包絡線は素通しになる。この2桁ずつの余裕が要点。D1 には **逆耐圧が必要** — 出力側が +Vpk に充電された状態で入力が −Vpk に振れるので、`2 × 24.5V = 49V` がかかる。1SS106 や BAT43（ともに 30V）では足りない。**1SS270A は DC 60V / ピーク 70V** で余裕がある。R1 が引く電流は 6W 時で 0.24mA、ダミーロードから見て 0.4% なので測定対象を乱さない。

### 検波プローブの読み方

出力は「ピーク電圧 − ダイオードの順方向電圧」。1SS270A の Vf はデータシートでは 0.8V だが、それは 100mA での値。**検波電流 0.12mA での実効値は約 0.5V** なので、これを差し引く。

`P [W] = (Vdet + 0.5)² / 100`

| 出力 | ダミーロード両端 | 検波出力 | Vf 補正しない場合の誤差 |
| --- | --- | --- | --- |
| 20 mW | 1.41 Vpk | 0.91 V | −58%（使えない） |
| 100 mW | 3.16 Vpk | 2.66 V | −29% |
| 500 mW | 7.07 Vpk | 6.57 V | −14% |
| **1.5 W** | **12.25 Vpk** | **11.75 V** | −8% |
| 6 W（変調ピーク） | 24.49 Vpk | 23.99 V | −4% |

**1V を下回る領域では二乗検波になって使えない**。搬送波そのもの（+4.7dBm = 0.54Vpk）は測れないので、そこはオシロで波形を確認するだけにして、レベルの判定は Driver 基板の出力（+20dBm）から行う。

絶対値だけは較正する

- 1SS270A はシリコンの高速スイッチング品で、**逆回復時間 3.5ns が 145MHz の半周期 3.45ns と同程度**。逆回復のあいだ電荷が入力側へ戻るため、**読みが低めに出る**。その量はデータシートから予測できない。
- **包絡線の形、変調度、整合のピーク探しは相対測定**なので、これは問題にならない。1SS270A 単独で足りる。
- 絶対電力だけは補正係数が要る。**1.5W 無変調なら逆電圧は 24.5V なので、30V のショットキ（1SS106 など）が安全に使える。**ダイオードを差し替えて同じ搬送波を読み比べれば、そのまま補正係数になる。ショットキ側は Vf 0.3V・逆回復ゼロなので、こちらを基準にする。
- 変調をかけた 6W ピークでは逆電圧が 49V になるので、**ショットキのまま送信しない**。較正が済んだら 1SS270A に戻す。

### NanoVNA でマッチングを追い込む

NanoVNA があれば、出力側の整合は**能動素子を載せる前に**片付けられる。入力側は素子を載せてから測るが、終段（C級）だけは小信号で追い込めないので大信号で決める。測る場所・目標・触る素子は基板別の手順（手順5・6）に、v000 基板での実測値は 16章にまとめた。

NanoVNA を壊さないために

- **送信状態で NanoVNA を繋がない。**CH1 の耐入力は +10dBm 前後。ドライバ出力（+20dBm）でも終段出力（+31.8dBm）でも一撃で壊れる。
- 測定前に必ず **CLK0 を停止するか、搬送波側の同軸を抜く**。
- 増幅段を通して S21（利得）を測るときは、**CH1 の手前に 20dB の減衰器**を入れる。NanoVNA の出力 −10dBm に 22dB の利得が乗ると +12dBm になり、上限を超える。減衰器を付けた状態で THRU 校正を取れば、読みがそのまま利得になる。

操作の基本（v000 の立ち上げで実際につまずいた点）

- **掃引範囲を決めてから校正する。**校正は範囲に紐づくので、範囲を変えたら取り直す。整合の追い込みは **100〜200MHz / 101点（1MHz/点）**、LPF と発振チェックは 100MHz〜1GHz。2GHz まで広げると 1点 18.6MHz になり 145MHz 付近が解像できない。
- **校正の基準面はケーブルの先端。**OPEN / SHORT / LOAD はケーブルの先に付けて取る。校正していないケーブルの先を測ると、長さに応じた大きなリアクタンスが見えるだけで何も分からない。
- **S21 は THRU（と ISOLN）まで取る。**THRU を飛ばすとケーブル2本の損失（145MHz で合計 0.3dB 前後）がそのまま挿入損失に乗る。
- **マーカーは周波数を手で入力して置く。**最小値サーチを使うと寄生共振の谷の底に乗り、実力より良く見える。
- **深さは LOGMAG（dB）で、インピーダンスはスミスチャートで読む。**SWR 表示はスケールを誤ると読めない。スミスの R + jX から `|Γ| = |Z − 50| / |Z + 50|`、`RL = −20·log|Γ|` で dB を検算できる。
- **発振チェックは S11 の LOGMAG で 0dB を超える点を探す。**受動回路なら S11 は必ず 0dB 以下。+1dB 以上の鋭いピークがあれば負性抵抗＝発振。0.5dB 以内のなだらかな超過は校正誤差。

### ① 素子を載せる前 — 抵抗置換法（S11）

整合回路が「計算どおりのインピーダンス変換をしているか」を、能動素子抜きで確認する。**Q3 と Q4 を実装する前に**やる。ドライバはコレクタパッドに **270Ω**、終段はドレインパッドに **3.3Ω** を仮付けし、出力側から S11（反射）を見て 145MHz で **−20dB 以下**に追い込む。

この2つは**ロードラインで決まる実数の抵抗値**への変換なので、抵抗で置き換えても本番とほぼ等価になる。仮付けする抵抗は **1% 品・リード最短**にする。ここの抵抗値がそのまま測定の基準になる。

どのツマミが何を動かすか — ドライバと終段で逆になる

- **ドライバ**は「負荷 270Ω に並列 C、その先に直列 L6、測定ポート」の順。並列 C が負荷に直接乗っているので、**並列 C（C39 または浮遊容量）が実部を決め、L6 は整合する周波数（虚部）だけを動かす**。L6 を伸ばすと谷が上の周波数へ、縮めると下へ動く。
- **終段**は「負荷 3.3Ω に直列 L10、その先に並列 C53、測定ポート」の順で、役割が入れ替わる。**L10 がスミスチャート上の「どの定コンダクタンス円に乗るか」（実部）を決め、C53 はその円に沿って動かす（虚部）**。C53 をどれだけ回しても中心に来ないときは、円が中心を通っていないので L10 を直す。
- どちらも**実部を決める素子を先に、虚部だけを動かす素子を後に**合わせると1往復で収束する。逆順にすると行ったり来たりになる。

抵抗置換法の落とし穴（v000 で判明）

- **並列 C には浮遊容量が乗る。**ドライバは必要な並列 C が 8.5pF しかないのに、コレクタ節点の浮遊が 6.63pF あった。トリマが最小端に張り付いたら、トリマを外して 145MHz の実部 R を読み、`C = √(R_L/R − 1) / (ω·R_L)`（R_L は仮付けした抵抗）で浮遊を逆算してから部品を決める。
- **素子を載せると容量が増える。**ドライバは Cob（約 1.5pF）が並列 C に加わる。**Cob と同じ値の C0G を空いたパッドに仮付けして合わせる**と、Q3 を載せたあとの状態を再現できる。終段の Coss はドレイン側（低インピーダンス側）に付くので影響は小さく、L10 は 14nH 前後に収まるが、必要な並列 C は 83pF → 86pF 程度動く見込み。**終段は −20dB を少し超えたら深追いしない**。
- **追い込んだら必ず抵抗を外す。**終段の 3.3Ω を付けたまま Q4 を載せて給電すると、`3.6V ÷ 3.3Ω = 1.1A` が流れ続ける。外したらテスタでドレインパッド〜GND が数百Ω以上あることを確認する。

### ② 素子を載せてから — 入力側の S11

入力インピーダンスはバイアス状態で変わるので、**電源を入れ、バイアスを規定値にした状態**で測る。出力側（J2）は必ず 50Ω で終端する。NanoVNA の出力は −13dBm 程度なので、素子はほとんど動かない。

- **ドライバ（Ic 35mA）**は小信号でも導通しているので、S11 で当たりがつく。目標 **−10dB 以下**、触る素子は L7 → C41。
- **終段（C級・Idq ≈ 0）**は小信号ではゲートが全く導通せず、S11 は 0dB 付近に張り付く（07章）。**ここでは整合の目標を置かず、発振していないことの確認にだけ使う**。L14 / C61 は大信号で決める。

小信号 S11 の限界

- C級動作では**入力インピーダンスがドライブレベルで変わる**。NanoVNA の −13dBm と、実際の +20dBm では Ciss の実効値もゲートの実部も違う。
- したがって入力側の追い込みは、最終的には大信号を入れて**「同じ出力を得るのに必要なドライブが最小になる点」**を探して決める。
- 逆に言えば、**出力側（抵抗置換法）は大信号でもほぼそのまま通用する**。ロードラインで決まる実数負荷への変換だから。

### ③ フィルタの通過特性 — S21

①②が「1つのポートに入れて跳ね返ってくる量」を見る**反射**の測定（S11）なのに対し、出力 LPF の検証だけは**通過**の測定（S21）を使う。NanoVNA の CH0 をフィルタの入口、CH1 を出口に繋ぎ、**入れた信号のうちどれだけ通り抜けたか**を見る。

「掃引」は、周波数を1点ずつ変えながら順に測っていく動作のこと。横軸が周波数・縦軸が dB のグラフが描かれるので、**通過域（145MHz）がほぼ 0dB で平ら、そこから上で急降下し、阻止域（288MHz / 432MHz）で深く落ちている**という形になっていれば正常。7次チェビシェフは阻止域に谷を持たない設計なので、**実測に現れる谷と山はすべて寄生の共振**。谷が浅いときの切り分けは手順6に書いた。

### 手順 1 — 通電前

1. **各レールと GND の間に短絡が無いこと。**+BATT / +8V / +3.3VA / +3.3VB / +17.4V をテスタで当たる。コンデンサの充電で値は上がっていくが、数Ωで止まるようなら実装ミス。
2. **向きの確認。**Q1（D=電池側 / S=負荷側）、電解コンデンサの極性。
3. **RV1 を 0V 側いっぱいに回す。**ゲートバイアス最小の状態から始める。
4. **基板間の同軸を全部抜き、R36 を外し、Final 基板の J4・J5 には何も繋がない。**全段が切り離された状態にする。

### 手順 2 — 電源

電流制限つき電源で 12.8V を与える。この時点の消費は **50mA 以下**のはず。

| --- | --- | --- |
| +8V | 7.98 V ±2% | R25 / R27 の分圧 |
| +3.3VA | 3.20 〜 3.40 V | BP5293-33 単体の出力（±3%） |

### 手順 3 — MCU と表示

I2C で Si5351A（0x60）と LCD（0x3E）が応答すること。LCD に文字が出ること。ここで **CLK0 はまだ有効にしない**。

### 手順 4 — 搬送波

CLK0 を有効化し、キャリア整形フィルタ（05章）の出力を 50Ω で終端して観測する。**Driver 基板にはまだ繋がない。**

- 周波数が設定どおりか（MultiSynth 偶数整数 ÷6、PLL 小数分周 — 05章）。
- レベル **+4.7dBm（0.38Vrms / 1.1Vpp）**前後。パッドを 3dB から振れば調整できる。
- 波形が正弦波に近いこと。方形波のままなら定数k LPF が効いていない。

### RF 基板の追い込み方

ここから先が RF 基板。相手の基板を繋がずに**1枚ずつ単体で追い込んでから、最後に同軸でつなぐ**。測りかたの原理は上の①②③、ここではそれを基板単位に並べ直し、実装状況・繋ぐ場所・使わない側のポートの扱いまで書いた。**各手順の v000 実測値は 16章**。

測定していない側のポートはどうするか

- **能動素子（Q3 / Q4）をまだ実装していない状態での抵抗置換測定は、反対側のポートを開放のままで良い。**整合回路の先は素子の未実装パッドで物理的に途切れているので、その先の入力ネットワーク（C40 → C41 → L7 → R29、または C51 → L14 → C60/C61）に何を繋ごうが、測定中のポートまで信号が伝わる経路自体が存在しない。
- **素子を実装してバイアスを与えた後の入力側 S11 測定は、反対側のポート（出力側）を必ず 50Ω ダミーロードで終端する。**素子が実在すると、出力側の終端状態が内部帰還（Cbc / Crss）を介して入力インピーダンスに影響し、開放だと発振もしやすくなる。

### 手順 5 — Driver 基板（単体）

Final 基板は接続しない。J1（入力）と J2（出力）はどちらも SMA。電源は +8V。

1. **Q3 を実装する前に出力側を追い込む。**Q3 以外の部品（R26 / R29 / R31 のバイアス分圧、C40 / C41 / L7 の入力整合、L6 の出力整合、デカップリング類）はすべて実装し、**C39 は実装しない**（06章）。Q3 のフットプリントは空のまま、**コレクタパッドと GND（エミッタ側のパターン）の間に 270Ω（1%）をリードを短く仮付け**し、**C39 のパッドに Cob の代役として 1.5pF の C0G を仮付け**する。NanoVNA を J2 に繋ぎ、J1 は開放のまま S11 を測る。\
   まず 100〜200MHz 全体を見て、整合の谷がどこにあるかを確認する。谷が 145MHz より低ければ L6 を伸ばし、高ければ縮める。**谷が 145MHz に来ても底が浅い（実部が 50Ω から離れている）ときは並列 C の過不足**で、L6 では直らない（上の「落とし穴」）。145MHz で −20dB 以下が目標。届いたら **270Ω と 1.5pF を外す**。
2. **Q3 を実装。**+8V を与える（ドライブはまだ入れない）。消費電流が 37mA 前後（Ie 35mA + バイアス分圧 2.2mA）であることを確認する。電流計が怪しいときは **Q3 のエミッタ電圧 ÷ 12Ω** で Ie を読む（v000: 0.415V = 34.6mA）。
3. **入力側の S11 を測る。**NanoVNA を J1 に繋ぎ、**J2 は 50Ω ダミーロードで終端する**。目標 −10dB 以下。触るのは L7 → C41。大信号では Zin が変わるので、ここは当たりをつける工程で、深追いしない。
4. **NanoVNA を外し、大信号で確認する。**J1 に 05章のキャリア整形フィルタ出力（+4.7dBm）を入れ、J2 にダミーロード＋検波プローブ。目標 **+20dBm（100mW）＝検波出力 2.66V** 以上。**平均電流はほとんど増えないのが正常**（エミッタ抵抗で固定）。**入力を増やしても出力が増えないときは、整合ではなく電流の天井**を疑う — 取り出せる電力は概ね `Ie² × 281Ω ÷ 2` で頭打ちになる。足りなければまず Ie（R32）、次に L7 → C41 → L6。v000 は Si5351A の CLK0 駆動を最小の 2mA にしても約 190mW（検波 3.90V）出た。信号源がまだ無ければ、NanoVNA の S21（CH1 の手前に 20dB 減衰器）で小信号利得だけ先に確かめられる。
5. **発振チェック。**ドライブを切っても J2 に何も出ないこと。怪しければ R29 を 10Ω → 22Ω に増やす。

ここまでで Driver 基板単体が完成。J1 に +4.7dBm を入れれば J2 から +20dBm（100mW）が出る状態になる。

### 手順 6 — Final（＋LPF）基板（単体）

Driver 基板は接続しない。J1（入力）と J2（出力）はどちらも SMA。電源は **J4 = ドレイン**（運用時は変調器の出力、調整中は安定化電源の 3.6V）と **J5 = 8V**（ゲートバイアス分圧だけが使う、0.32mA）の2系統。R36 は 07章の整合と 08章の LPF の間を切り離す、基板内に残る唯一の 0Ω で、その隣にある GND のテストポイント（Final 基板の回路図上の TP1）が NanoVNA の網線を落とす点になる。

1. **LPF 単体を先に検証する（R36 を外したまま）。**NanoVNA の **CH0 をピグテールで R36 の LPF 側パッド**、**CH1 を J2** に繋ぐ。100MHz〜1GHz で SOLT・ISOLN・**THRU** まで校正し、S21 を LOGMAG で見る。マーカーは 145 / 288 / 432MHz に手で置き、288MHz は 284〜292MHz の中の最悪値を読む。同じ接続のまま S11 も見て 145MHz のリターンロスを確認する。\
   目標は 145MHz で **−0.3dB 以内・リターンロス 20dB 以上**、288MHz で **−50dB 以下**。432MHz は計算上 −78dB だが実基板では −40dB 台で頭打ちになりうる（v000 は −41dB）。3倍波の合否は手順9で決める。\
   **阻止域が浅いときの切り分け**（v000 で実施した順）: ① CH0 のピグテールを基板から浮かせて S21 を測る → これが測定系の床（v000: 433MHz で −65dB）。② フィルタ中央の L12 の片脚を浮かせる → これがフィルタを通らない経路の床（v000: −56dB）。③ 実測がこの2つより十分浅ければ、漏れはフィルタの素子を通っている。v000 ではコイルの向きを変えても効かなかった（08章・ADR-022）。**Q4 を実装する前に済ませる** — 実装後も R36 を外せば測れるが、コイルの向きを変えるような手直しは素子が無いうちのほうが楽。
2. **Q4 を実装する前に出力側を追い込む。**Q4 以外の部品（RV1 / R33 / R34 / R35 / L9 のゲートバイアス回路、C51 / L14 / C60 / C61 の入力整合、C50 / C52 / C53 の出力整合、L8）はすべて実装しておく。Q4 のフットプリントは空のまま、**ドレインパッドと GND（ソースのタブ）の間に 3.3Ω（1%）をリードを短く仮付け**する。R36 は外したまま、NanoVNA の CH0 を **R36 の整合回路側パッド**（網線は TP1）に繋ぎ、J1 は開放。100〜200MHz で SOLT 校正して S11 を測る。\
   **L10 → C53 の順**に合わせる（L10 が実部、C53 が虚部）。目標 −20dB 以下。**C53 の位置を必ず記録する** — 最大端に張り付いたら C52 を大きく、最小端なら小さくする（v000 は 47pF → 56pF に変更）。−20dB を少し超えたら深追いしない（Q4 の Coss で最適点が少し動く）。\
   **任意**：3.3Ω を付けたまま R36 を実装し、J2 から S11 を見ると「3.3Ω → 整合回路 → LPF」全体を一度に確認できる。−15dB 前後が見えれば出力系統は正常。\
   最後に **3.3Ω を外し、ドレインパッド〜GND が数百Ω以上あることをテスタで確認**する。
3. **Q4 を載せる前に RV1 の素性を確かめる。**RV1 を 0V 側いっぱいにして J5 に 8V を入れ、テスタを **Q4 のゲートパッド**に当てて RV1 を全域回す。**0V 〜 3.20V（±5%）**で滑らかに動くこと、**どちら向きが「上げる」か**を記録する。多回転（25回転）なので向きを覚えておかないと次で間違える。確認したら RV1 を 0V 側へ戻し、8V を切る。
4. **Q4 を実装して給電する。**RV1 が 0V 側にあることを確認して Q4 を実装し、R36 を実装、J2 に 50Ω ダミーロードを繋ぐ。J4 への給電線に電流計を直列に入れる。**投入は J5（8V）が先**で、ゲートが 0V であることを確かめてから **J4 に 3.6V（電流制限 100mA）**。ドレイン電流がほぼ 0 であること。\
   遮断は逆順で、**RV1 を 0V 側へ → J4 を切る → J5 を切る**。\
   安定化電源が1台しかなければ、**J5 は 9V 乾電池（006P）を直結**すれば足りる。負荷は 0.32mA で、ゲートの可動域が 0〜3.6V 程度に広がるだけで害はない（Vgs 定格 ±20V 級）。電池の − と電源の − と基板 GND は必ず共通にする。
5. **ゲートバイアスを決める。**RV1 をゆっくり上げ、**ドレイン電流が 1mA 流れ始めたときのゲート電圧**を Vgs(th) として記録する（1.5〜2.5V のどこか）。そこから **0.3〜0.5V 戻し**、Idq が 0〜10mA に収まることを確認する。RV1 の回転位置ではなく**ゲート電圧を記録する** — 8V の値が変わっても引き継げる物理量はこちら。\
   Vgs(th) は負の温度係数（約 −4mV/℃）を持つので、ダイが 60℃ 上がると 0.24V 下がる。浅く戻した（0.3V 程度）場合は、手順9で温まってから Idq を測り直す。
6. **入力側 S11 で発振していないことを確かめる。**ゲートバイアスを規定値、ドレイン 3.6V、**J2 は 50Ω ダミーロード**の状態で NanoVNA を J1 に繋ぐ。100MHz〜1GHz を S11 の LOGMAG で見て、**0dB を超える点が無いこと**。145MHz のインピーダンスも参考に記録しておく。**ここでは整合を追い込まない** — C級のゲートは小信号で導通しないので、S11 は 0dB 付近に張り付くのが正常（07章）。
7. **NanoVNA を外し、低ドライブから大信号で整合する。**電源の電流制限を **1.5A** に上げる（1.0A だと変調の山に相当する電圧で CC に入り、出力を削る。v000 で実際に起きた）。J1 に 20mW 程度の信号を入れ、J2 にダミーロード＋検波プローブ。**L10 を伸縮して出力最大点、次に C53**。続けて **L14 を伸縮して利得最大点（同じ出力を得るのに必要なドライブが最小になる点）、次に C61**。この2つを 2〜3 往復させる。規定ドライブ（100mW）まで上げ、ドレイン 3.6V で 1.5W（検波出力 11.75V）、ドレイン電流 0.6〜0.7A（効率 65% 前後）を確認。
8. **発振チェック。**ドライブ切、バイアス振り、ドライブ量変化のそれぞれで SDR に何も出ないこと。

ここまでで Final 基板単体が完成。J1 に 100mW 入れれば J2 から 1.5W が出る状態になる。

### 手順 7 — 変調器単体

変調器（M3）の出力を Final 基板の J4 に繋がず、単体でオシロで見る。RF 段は動かさない。**ここを飛ばして終段に繋がないこと** — 変調器が暴れた状態で給電すると一発で飛ぶ。

R8 とファームウェアの定数は対で変える

- R8 は 22kΩ（ゲイン 3.2）。ファームウェアは**搬送波 87 / 絶対上限 187** の版を書き込んでから始める（ADR-024、ファームウェア仕様書 §6・§11）。
- 旧定数（93 / 200）のまま R8 = 22k に繋ぐと、搬送波が 3.84V、上限が 8.25V 相当の指令になる。**上限側は 8V レールに張り付き、終段の損失が約 6.3W**（03章）に達する。
- 確かめ方は下の表の最終行。シリアルから 200 を指令して 7.7V 前後で止まれば新しい定数が入っている。

| デューティ | 期待される出力 |
| --- | --- |
| 0（無信号） | 0 V |
| 0.341 固定（レジスタ 87） | 3.6 V ±0.1V で静止 |
| 0.341 ± 0.311 | 0.72 〜 6.48 V の 700Hz 正弦波 |
| シリアルから 200 を指令 | 7.7 V 前後で止まる（ファームウェアが 187 に丸める）。8V に張り付いたら定数が旧版のまま |

**変調器の出力には 1kΩ（1/4W）のダミー負荷を付けて測る。**ソースフォロワは電流を吸い込めないので、出力を下げるときは負荷が放電を受け持つ。出力には 0.1µF（03章）が付いているので、無負荷だと放電は帰還抵抗 R5＋R8（32kΩ）だけになり、700Hz の下り坂（最大 12.7V/ms、0.1µF で 1.27mA 必要）に追従できない。**波形は「速く上がって直線的に下がる」のこぎり波になり、振れ幅も小さく見える**（v000 で実際に起きた。変調器の不良ではない）。追従には 2.8kΩ 以下の負荷が要るので、余裕を見て 1kΩ（損失 最大 42mW）。直流の確認（デューティ 0 / 84 / 上限）は無負荷でもよい。

波形の頭や谷が潰れている場合、オペアンプの振れ幅か 8V レールの落ち込みを疑う。**RF 側の整合まで戻らず、ここで直す。**

### 手順 8 — 2枚を接続して変調

1. **Driver 基板の J2 と Final 基板の J1 を SMA＋短い同軸で接続する。**ここで初めて全段が繋がる。搬送波側の同軸も繋ぐ。
2. **変調器の出力を J4 に、8V レールを J5 に繋ぐ。**ダミーロードに検波プローブを当てて包絡線を観測する。調整中にドレインへ足したコンデンサがあれば、ここで必ず外す（0.1µF まで。12章）。
3. **変調度を測る。**`m = (Vmax − Vmin) / (Vmax + Vmin)`。搬送波 24.6Vpp なら、80% は **山 44.1Vpp / 谷 4.9Vpp**。
4. **谷が沈みきらない場合。**Idq を下げる方向で RV1 を回す。それでも駄目ならドライブを絞る。負変調は 70〜85% で頭打ちになりやすい。
5. **頭が潰れる場合。**デューティ振幅を下げる。8V レールの落ち込みも確認する（変調ピークで 7.4V を割っていないか）。
6. **最終的に振幅 0.311 で 80% に合わせる。**搬送波レベルは中心 0.341 で独立に決まるので、互いに影響しない。

### 手順 9 — スプリアスと連続運転

- **高調波。**290MHz と 435MHz が **−60dBc 以下**。LPF の実測は 289MHz −53dB / 433MHz −41dB なので、2倍波は余裕があるが、**3倍波は終段自身の3倍波が −20dBc より悪いと要件を割る**。割ったら出力に外付けの同軸 LPF を1段足す（ADR-022）。
- **近傍のスプリアス。**±250kHz（PWM 残留）、±24.3kHz（デューティ更新レートの折返し）、±340kHz/±570kHz 前後（降圧DC-DC ×2）、±300kHz（チャージポンプ）。
- **占有周波数帯幅。**A2A なら ±3kHz 以内に収まること。トーンが正弦波でないと奇数次側波帯が延々と出る。
- **キーイング。**立ち上がり・立ち下がりを 5ms 程度なまらせ、クリックが出ないこと（04章）。
- **連続 30分。**終段と変調器 MOSFET の温度が飽和すること。飽和せず上がり続けるなら放熱不足。
- **温まってから Idq を再確認。**Vgs(th) は温度で動くので、冷間で合わせた値からずれる。

調整中にやってはいけないこと

- **R36 を外したまま送信しない。**終段が無負荷になり、ドレイン電圧が跳ね上がって素子を失う。
- **アンテナ未接続で送信しない。**ピークで 6W 出る。
- **RV1 をいきなり回し上げない。**必ず 0V 側から、電流を見ながら。
- **抵抗置換用の 270Ω / 3.3Ω を付けたまま素子を載せて給電しない。**終段は 1.1A が流れ続ける。
- **電源の順序を崩さない。**Final 基板は J5（8V）→ J4（ドレイン）の順に入れ、逆順で切る。R34 がゲートを 0V へ引くので逆にしても即座には壊れないが、FET の電力段の定石として守る。
- **手順 7（変調器単体）を飛ばさない。**変調器が暴れた状態で終段に給電すると一発で飛ぶ。

## 12設計上の注意

### 回路の落とし穴

- **ドレインに大容量のバイパスコンデンサを入れない。**通常の PA なら 100µF を入れる場所ですが、ここは音声を通す経路そのものです。100µF を 1kHz・3.6V で振るには `I = C·dV/dt = 2.3A` 必要で、変調器が供給できず変調が潰れます。**0.1µF まで**。RF の帰り道は RFC の手前で確保します。
- **終段ドレインの瞬時最大電圧は約 14.4V。**C級では変調ピーク電圧の約 2 倍が瞬間的にかかります。変調ピーク 7.2V での通常運用と同じ値なので問題ありません。ドレインの直流電圧は 8V レールが上限を決めるので、それ以上には上がりません。
- **変調器 MOSFET の損失は最大 3W 前後。**ドレイン 4V で最大になり、搬送波（3.6V）はそのすぐ近く。v000 の実測から約 2.9W、変調中の平均は約 2.1W。**3.5W で設計**し、ケース側板＋外付けヒートシンクで逃がす（03章「2SK4017 の引き出しと放熱」）。
- **負変調は 70〜85% で頭打ちになりやすい。**変調度 80% なら谷のドレイン電圧は `3.6 × 0.2 = 0.72V` で、膝電圧（約 0.6V）のすぐ上です。ここで終段は飽和 C級から外れるのに、ゲートには満振幅のドライブが入り続けているため、残留導通と Crss の素通りでキャリアが抜けきりません。**A2A ではこれで十分実用**なので、本機はここを追わない（ADR-017）。

### 実装の注意

- **SOT-89 の放熱。**終段の損失は搬送波時で約 0.7W（v000 で電源電流から換算。設計時の見込みは 1.5W）と、通常運用では小さい。それでも異常時に跳ね上がるので経路は省かない。SOT-89 は熱抵抗が高いので、タブ下にベタ銅箔＋サーマルビアは必須です。可能なら基板裏からケースに熱結合してください。ここを軽く見ると変調ピークで素子温度が限界を超えます。**目標は 10°C/W 以下** — 変調基準が 3.3V に張り付いて 8V 連続になっても損失 6.3W / 温度上昇 63°C で収まり、素子を失わずに済みます（03章）。
- **電源部と RF 部でベタGNDを分け、1点接続。**8V ラインにフェライトビーズ + 0.1µF。降圧DC-DC のインダクタは RF 部から離し、できれば仕切り板を入れます。
- **基板サイズの目安。**ブレッドボードに残る側は、変調器 30×30mm、RT8250（8V）が 22×17mm、BP5293-33（3.3V(A)）が 16×16.8mm、倍電圧 12×12mm。最終的に1枚へまとめるなら、RF 部と合わせて片面 90×60mm 程度に収まる規模です。

### 基板の分割

RF 部は **Driver 基板**（06章）と **Final＋LPF 基板**（07・08章）の2枚に分けて起こしてある。残り（M2 / M3、電源、MCU / Si5351A / LCD）はブレッドボード。

- **利得のある2段はブレッドボードに載せない。**接触列は1cmあたり5〜10nHのインダクタンスを持ち、145MHzでは4.6〜9.1Ωの直列インピーダンスになる。3.5Ω系のドレイン整合や50Ω整合にとって無視できない大きさで、しかもグラウンドリターンが不定になるため段間や電源との帰還ループができやすい。fT=6GHzの2SC4703やLDMOSはこの手の帰還に敏感なので、この2段だけは基板で作る。
- **終段基板には LPF も同居させる。**07章のドレイン整合と08章のLPFは3.5Ω→50Ω変換の直後でつながっているので、この区間を基板外に出すと反射・漏れ結合の原因になる。だから Final 基板は「終段＋LPF」を一体として設計してある。
- **基板間の RF は SMA コネクタ＋短い同軸で接続する。**コネクタの GND ピン／シェルを基板のベタ GND に直接ハンダ付けすれば、同軸のシールドが信号と常に同じ経路を通るため、別々のワイヤで GND だけ引き回すよりも結合インダクタンスが小さく安定する。SMA を段間に置いたことで、NanoVNA での追い込みもダミーロード終端も**コネクタの抜き差しだけ**で済む（11章）。
- **u.FL ではなく SMA を選ぶ。**u.FL は抜き差し耐性が数十回程度しかなく、NanoVNA で整合を追い込む過程で規定回数を超えやすい。SMA は 500 回程度の抜き差しに耐えるので、調整段階では SMA 一択。
- **1枚にまとめる段になったら 0Ω に差し替える。**最終的に RF 部を1枚の基板へまとめるときは、SMA コネクタを外して **R28 / R37**（0Ω、または直接パターン）とテストポイントに置き換える。基板内の **R36** はそのまま残す — LPF 単体を掃引できる唯一の切り離し点なので、1枚基板でも必要。

### 運用の注意

- **アンテナ未接続で送信しない。**ピークで 6W 出るので終段が飛びます。調整は必ずダミーロード（50Ω / 10W）で。野外に放置するなら簡易的な反射電力検出で送信を止める仕組みがあると安心です。
- **トーンは必ず正弦波で。**方形波で変調すると ±3kHz、±5kHz と奇数次側波帯が延々と出て占有周波数帯幅をオーバーします。キーイングの立ち上がり・立ち下がりも 5ms 程度なまらせるとクリックが出ません。
- **A2A は搬送波を出しっぱなし。**キーイングするのはトーンだけで、キャリアは連続。ここを間違えると A1A になります。

運用前に必要な手続き

- 自作機のため、TSS または JARD の保証認定（工事設計書 + スプリアス確認）を経てから変更申請が必要。
- スプリアス発射の強度は必ず実測で確認する。手元の測定は RTL-SDR ＋ 減衰器で行うが、保証認定でスペアナ実測を求められる場合があるので、JARD のスプリアス確認保証の要件は事前に確認する。2倍波が落ちきらない場合の追加策は ADR-007、3倍波は ADR-022。
- 144MHz 帯のバンドプランで A2A が使える区分かを確認してから送信すること。

## 13手巻きコイルの製作

手巻きにする 8本はすべて空芯で自作する。**φ0.65mm ポリウレタン線（2UEW、外径 0.694mm）を φ5mm（L10 / L14 は φ3mm）の丸棒に巻く**前提で定数を出した。平均直径は `心棒径 + 0.65mm`。巻数と巻き長はホイーラーの式による。チップで代用するコイル（L1〜L3、L4、L9）はここには含めない。使い分けの判断は次項を参照。

| 記号 | 用途 | 心棒 | 目標 | 巻数 | 巻き長 | ピッチ | 密着巻き時 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| L8 | 終段ドレイン給電 | φ5 mm | 0.47 µH | 14 T | 10.6 mm | 0.75 mm | 0.50 µH |
| L6 | ドライバ出力整合（可変） | φ5 mm | 120 nH | 6 T | 6.9 mm | 1.15 mm | 169 nH |
| L12 | 出力 LPF 中央 | φ5 mm | 78 nH | 4 T | 3.9 mm | 0.98 mm | 95 nH |
| L11 / L13 | 出力 LPF 両端 | φ5 mm | 71 nH | 4 T | 4.5 mm | 1.13 mm | 95 nH |
| L7 | ドライバ入力整合（可変） | φ5 mm | 56 nH | 4 T | 6.4 mm | 1.61 mm | 95 nH |
| L14 | 終段入力整合（可変） | **φ3 mm** | 33 nH | 4 T | 4.7 mm | 1.18 mm | 48 nH |
| L10 | 終段出力整合（可変） | **φ3 mm** | 14 nH | 2 T | 2.1 mm | 1.05 mm | 17 nH |

手巻きにするのは 8本で、必要な線材は総延長で約 87cm（リード分込み）。10m 巻きを1本買えば足りる。心棒は **L10 と L14 が φ3mm、残り6本は φ5mm**。丸棒はドリルの軸で代用できる。

可変コイルの目標値は出発点で、最後は実測で決まる。v000 基板で追い込んだ結果は **L6 ≈ 116nH**（設計 120nH）、**L10 ≈ 14.1nH（リード込み）**（設計 14nH）。L10 は見た目がかなり広がった状態で合ったが、リードのインダクタンスが加わっているためで、値としては正しい。L7 / L14 は大信号で決めるので未確定（16章）。

小さい値のコイルは心棒を細くする

- 目標が小さいコイルを φ5mm で作ると、巻数が足りないぶんを**ピッチを広げて稼ぐ**ことになる。線径 0.694mm に対して隙間が線径以上に開くと「ほぼバネ」になり、手で触れただけで形が変わってインダクタンスが動く。
- **L10（14nH）**は φ5mm だと 2回でピッチ 3.2mm（隙間が線径の 3.6倍）。**φ3mm で 2回・ピッチ 1.05mm** にすると隙間は線径の半分に収まる。
- **L14（33nH）**も同じ問題で、φ5mm・3回だとピッチ 2.01mm（隙間が線径の 1.9倍、密着巻きの 2.9倍まで引き伸ばすことになる）。**φ3mm・4回・ピッチ 1.18mm** なら隙間は線径の 0.49倍で、引き伸ばし率も 1.7倍に収まる（ADR-018）。
- 可変コイルは伸縮させて追い込む前提なので、**目標値が可動域の真ん中あたりに来る**のが望ましい。L14 は φ3mm・4回にすることで、目標域 29〜35nH が巻き長 4.35〜5.59mm という扱いやすい幅に対応する。

L8 に 1µH は要らない

- チョークに求められるのは「145MHz でドレインの負荷 3.5Ω に対して十分高いこと」だけ。**0.47µH でも 471Ω = 134倍**あり、負荷への影響は 0.7% にとどまる。
- 長いソレノイドでは `L = µ₀ N A / p` なので、**巻数は L に比例し、直径の2乗に反比例**する。1µH のままだと φ5mm で 27回・20mm になるが、0.47µH なら **14回・10.6mm** で済む。
- 線長は 479mm → 248mm、DCR は 24.8mΩ → 12.9mΩ。自己共振も 331MHz → 482MHz と遠ざかる。
- 心棒を φ10mm にして 1µH のまま 11回にする手もあるが、直径が増えるぶん磁界が広がって出力 LPF と結合しやすい。**φ5mm で統一するほうが実装が楽**。
- C43（0.01µF）との直列共振は 73MHz。ここには何も存在しないので問題ない。

チョークに磁気シールド品は要らない

- B82498F は非シールドのドラムコアだが、**L4 / L9 が扱う RF 電流は 1〜3mA しかない**ので、外へ漏らす磁束は問題にならない。
- 逆に拾う側も心配ない。最も電流の大きい L10（ピーク 1.31A）が L9 に `k = 0.01` という密結合をしたとしても、ゲート節点に現れるのは 1.4mV で、ドライブ 2.7V に対して **−66dB**。終段の利得 12dB を足してもループ利得 −54dB で、発振には遠く及ばない。
- シールド品は磁性体でモールドする構造なので、**SRF と Q が下がる**。チョークにとって一番大事なのが SRF なので、この用途では不利な取り引きになる。B82498F の SRF 440MHz は非シールドだから得られている。
- シールドが意味を持ちうるのは**出力 LPF をチップ化する場合**だけ。チップにするならシールド品を選ぶ。

### 巻き方

1. **必ず密着巻きしてから伸ばす。**伸ばすとインダクタンスは減る一方なので、目標より大きい状態から近づける。表の「密着巻き時」が出発点。
2. **心棒から抜くと直径が 0.2〜0.4mm 広がる。**インダクタンスが数% 増えるので、抜いた状態で実測して巻き長を詰める。
3. **両端に 10mm のリードを残す。**被覆はライターで焼いてから磨くか、はんだ槽に浸ける。
4. **固定コイル（L8、L11〜L13）は形を接着で固める。**可変の4本（L6 / L7 / L10 / L14）は追い込みが終わってから固定する。

### 実装上の制約

- **出力 LPF の L11 / L12 / L13 はパッドの並びどおりに実装する。**L12 の footprint だけ 90° 回してあるのは隣と軸を直交させるための意図的なもので、見た目を揃えて同じ向きにしない。間隔は直径の2倍以上。なお v000 ではコイルを基板に垂直に立てる実験もしたが 433MHz の減衰はほぼ変わらず、コイル間の結合は支配的な要因ではなかった（08章・ADR-022）。
- **L8 は LPF から離す。**直径が一番大きいコイルなので、軸を LPF と直交させ、できれば基板の反対側へ寄せる。
- **L8 の直流特性。**DCR 12.9mΩ でピーク 1.5A でも 19mV しか落ちない。空芯なので飽和は原理的に存在しない。自己共振は約 482MHz で 145MHz から十分離れており、実効インピーダンスは 471Ω。負荷 3.5Ω に対して 134倍あり、影響は 0.7%。
- **測定は VHF で。**LC メーターは 100kHz 前後で測るので VHF での実効値とずれる。NanoVNA があれば既知のコンデンサと直列共振させて求めるのが確実。

## 15参考：マイク入力（A3E への拡張）

現時点では A2A のみを対象とする。将来 A3E（音声 AM）に広げる場合の入り口だけを、確定した数値として残しておく。**マイク出力をアナログのまま Audio ノードへ入れるのではなく、MCU の ADC に入れてソフトウェアで扱う**。理由は下記。

### Audio ノードに必要な信号

M3 は帰還で 1/3.2 に分圧しているので、**ドレイン電圧 = Audio × 3.2** がそのまま成り立つ。ここは A2A のトーンと共通の仕様。

| 項目 | 値 | 意味 |
| --- | --- | --- |
| 直流 | 1.125 V | 搬送波レベルそのもの（ドレイン 3.6V） |
| 交流 | ±0.90 Vpk | 変調度 80% |
| 下限 | 0.225 V を切らない | ここで変調度 100%。割るとキャリアが切れてスプラッタ |
| 上限 | 2.025 V を超えない | ドレイン 6.5V 相当。8V レールが構造上の天井 |
| 帯域 | 300 Hz 〜 3 kHz | 占有帯域を抑える |

**直流が搬送波レベルである**ことがこの回路の特徴。マイクアンプの出力を交流結合でそのまま入れると直流が失われ、搬送波が消える。

### マイクが出せるレベル

秋月 **AE-SPU0414**（Knowles SPU0414HR5H-SB）。感度 −22dBV/Pa（ゲインジャンパ短絡時）＝ 94dB SPL で 79mVrms。出力の直流バイアス 0.93V、出力インピーダンス 400Ω。

| 状況 | 音圧 | 出力 |
| --- | --- | --- |
| 5cm で普通に話す | 85 〜 90 dB | 25 〜 50 mVrms |
| 音声のピーク（波高率 12dB） | — | **100 〜 200 mVpk** |
| モジュール自体の飽和 | 105 dB 付近 | バイアス 0.93V から下へ約 0.5V |

必要な 0.90Vpk まで持ち上げるゲインは **6〜20倍（16〜26dB）**。ただしこの倍率をアナログで固定するのは筋が悪い（次項）。

アナログでやらない理由

- **過変調が最大の問題。**音声は波高率が大きく、声量も距離も一定しない。ゲインを固定すると、小さい声では変調が浅く、少し大きい声で 0.225V を割る。**割った瞬間にキャリアが切れて占有帯域が一気に広がる**。リミッタは「あったほうがいい」ではなく必須。
- **窓が非対称。**1.125V を中心に下は 0.225V まで、上は 2.025V まで。ダイオードクリップで作れるのは ±0.6V か ±1.2V の刻みで、欲しい ±0.90V に合わない。
- **直流台座を別に作る必要がある。**反転増幅の + 入力に 1.125V を与える構成になり、オペアンプ・基準電圧・A2A との切り替えスイッチが増える。
- ADC 経由なら、リミッタも帯域制限もコンプレッサも**数値で書けて、しかも絶対に守られる**。追加部品は抵抗3本とコンデンサ3個だけ。

### 接続

追加部品は抵抗3本とコンデンサ3個だけ。`0.01µF` とバイアス分圧 50kΩ で **fc 318Hz のハイパス**になり、これがそのまま音声帯域の下端になる。ハンドリングノイズや吹かれも入り口で落ちる。`1kΩ + 47nF` は fc 3.4kHz のアンチエイリアス。マイクの電源は **+3.3VA** から取り、Si5351A の +3.3VB とは分けたままにする。**バイアス分圧の上側（R12）もマイクの電源と同じ「100Ω の後」から取る**（下記）。

### 処理はすべてソフトウェア側

やっていることは **ADC → ソフトウェア処理 → PWM（1ビットDAC）** の一本道で、**出力側の経路は A2A とそのまま共有する**。したがって A2A と A3E の違いは「変調入力に何を入れるか」だけになり、回路としては何も変わらない。

帯域制限（300Hz〜3kHz）、コンプレッサ、過変調を防ぐリミッタ、そして下記の周波数特性の補償は、いずれも**ファームウェア仕様書**の規定による。ここではハードウェア側の条件だけを挙げる。

帯域内の傾きをソフトで補償する必要がある

- マイク側のアンチエイリアス（1次 LPF、fc 3386Hz）と出力側の M2（2段 RC）が、どちらも音声帯域の中で効いてくる。3kHz では **アンチエイリアスが −2.5dB、M2 が −8.5dB、合わせて −11dB**。
- A2A（700Hz 単一トーン）では定数 0.877 で補正済みなので無関係だが、**A3E ではそのままだと音声がこもる**。
- この傾きは既知の固定特性なので、ファームウェア側のイコライザで打ち消せる（1kHz 基準で 3kHz を +8.6dB）。M2 の定数を変えて傾きを減らす選択肢もあるが、fc を上げると PWM 残留の減衰（現状 250kHz で −74.7dB）が悪化する。**A3E に着手する時点で改めて判断すること。**

### 実装の注意

- **マイクの電源は +3.3VA に 100Ω + 10µF を介して与える**（R10 / C12、fc 約 160Hz）。ゲインが高いので、MCU レールのノイズがそのまま音声に乗る。C12 はモジュールの近くに置く。
- **バイアス分圧の上側（R12）も R10 / C12 の接続点から取る。**+3.3VA に直結すると、分圧で 1/2 になっただけのノイズがマイクを通らずに ADC へ入る（マイクの電源除去も RC も効かない）。R12 の電流は 16µA なので R10 での降下は 1.6mV。ESP32 の ADC は内部基準なので電源ノイズは打ち消されない。
- **ゲインジャンパは短絡する。**基板裏のジャンパを半田で埋めて +20dB 側にする。
- **ADC のバイアスは 1.65V。**音声のピークが ±100〜200mV 程度なので 12bit のレンジの数% しか使わない。**実効分解能は 9bit 弱**まで落ちるので、ソフトウェア側のコンプレッサは「あると良い」ではなく実質必須になる。
- **アンチエイリアスは 1次で妥協している。**25kHz サンプリングに対して fc 3.4kHz の 1次では 12.5kHz で −11dB。音声にはこの帯域の成分がほとんど無いので実用上問題ないが、気になるなら RC をもう1段足す。
- **ADC は D1（GPIO1）。**ESP32-C6 は GPIO0〜2 しか ADC に使えず、D0 はバッテリー監視で埋まっている（04章のピン割り当て）。
- **A3E も保証認定で申請しておく。**A2A だけで通すと、あとで電波型式の変更申請が必要になる。

### ここから分かったこと

- **検波プローブに直流阻止の C を入れてはいけない。**R1 の直流の帰り道が無くなり、出力が 0V のまま動かない（初版の設計の誤り。14章の回路図を修正済み）。
- **エミッタ抵抗でバイアスしたドライバは、ドライブで平均電流が増えない。**出力の上限は Ie で決まる。入力を増やしても出力が増えないときは整合より先に電流を疑う（ADR-025）。
- **8V レールが 11.6V になっていた時間があった**（DC-DC の設定ミス）。Q3・R32・8V の電解（16V 耐圧）とも DC 測定で異常なし。大信号の出力も正常に出ている。
- **抵抗置換法は浮遊容量の実測を兼ねる。**整合が合わないとき、並列 C を外して実部を読めば、パターン側に何 pF 乗っているかが分かる。
- **必要な並列 C が小さい整合は、浮遊で大半が埋まる。**ドライバ出力は必要 8.5pF に対して浮遊 6.63pF。トリマの最小容量が邪魔をして C39 は要らなくなった。
- **素子を載せたあとに加わる容量は、代役の固定 C で先に再現できる。**Cob 1.5pF の代役を仮付けして合わせた結果、予測 54.0 − j0Ω に対して実測 53.4 − j2.2Ω と、1% の精度で合った。
- **ドライバと終段で、整合のツマミの役割が逆になる。**並列 C が負荷側にあるか測定ポート側にあるかで決まる（11章）。
- **C級の終段入力は小信号で測れない。**データシートの Zs は AB級（Idq 500mA）の値で、Idq ≈ 0 のゲートは −13dBm では導通しない。
- **LPF の 3倍波の頭打ちはコイル間の結合ではなかった。**向きを変えても動かず、鎖を切ると 15dB 深くなる。v001 のグランド処理の課題（ADR-022）。
- **NanoVNA の操作で結果が大きく変わる。**掃引範囲ごとの校正、ケーブル先端での校正、マーカーを手で置く、深さは LOGMAG で読む — 11章の「操作の基本」に反映した。

### 残っている作業

回路としての確認はここで一区切り。変調器・電源・MCU はブレッドボードのままなので、**配線や GND に左右される調整は、PCB に移してからやり直す**。

1. （任意・PCB の前）SDR で、搬送波の近く（±250kHz、±1.2MHz が消えたか）と 3倍波（435MHz）を「目立つものが無いか」だけ見る。
2. 回路図を更新して PCB に移す（R32 12Ω、R1 100Ω、C6 の付け替え、オペアンプのパスコン、R8 22kΩ、ドレイン電流の測定端子、オシロ用 GND 端子）。**2SK4017 は J6 / J7 で引き出してケース側板＋外付けヒートシンク**（C5 追加、03章）。マイクは R10 / C12 を追加し、R12 もその後ろから取る（15章）。
3. PCB で：搬送波の校正（`MOD_K_CAL`）、変調度 80%、近傍スプリアス、3倍波の合否、連続 30分（ヒートシンク根元 60°C 以下）、熱間の Idq。2SK4017 を引き出したので、発振の確認は J13（TP2）を 1µs/div に加えて 10〜20ns/div でも見る。
