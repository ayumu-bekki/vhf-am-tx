# vhf-am-tx

Seeed Studio XIAO ESP32C6 を用いた 144MHz帯 終段ドレイン変調 AM(A2A / A3E)送信機プロジェクト。
ARDF(アマチュア無線方向探知)用のフォックスハンティング送信機(A2A)および音声AM送信機(A3E)として動作します。

## 主な仕様

- **送信周波数**: 144.000 〜 146.000 MHz(20 kHz ステップ、Si5351A PLL制御)
- **電波型式**:
  - **A2A**: トーン変調電信(700 Hz 正弦波、ARDF 5分サイクル・MOE/MOI/MOS/MOH/MO5・MO連続送信対応)
  - **A3E**: 振幅変調電話(MEMSマイク入力・デジタル音声信号処理 300 Hz〜3 kHz)
- **送信出力**: 搬送波 1.5 W / 変調ピーク 6.0 W(終段 LDMOS `HTL7G06S006P`)
- **変調方式**: 終段ドレイン変調(高レベル変調：250 kHz PWM + 2段RCフィルタ + `NJM2125F` / `2SK4017` シリーズパスレギュレータ)
- **電源電圧**: DC 12.8 V(4S LiFePO4 バッテリー、10.5〜17 V 対応、低電圧警告・送信禁止保護機能付き)
- **ユーザーインターフェース**: I2C キャラクタ LCD(`AQM0802A` / ST7032)+ 3ボタン操作(Mode / Fn+ / Fn-)

## ビルドとテスト

### ファームウェアのビルド・書き込み

本ファームウェアは **ESP-IDF**(ターゲット: `esp32c6`)を使用します。

```sh
cd app/vhf-am-tx
idf.py set-target esp32c6
idf.py build
idf.py flash monitor
```

> **Note**: 実機で USB ケーブルを接続して書き込みを行う際は、基板上のジャンパ `J12`(BP5293-33 3.3V出力 ↔ XIAO 3V3)を取り外し、電源の競合を避けてください。また、ベンチテスト時やデバッグモードを有効化する場合は `idf.py menuconfig` の `AM Transmitter` メニューから設定を変更できます。

### ホスト単体テストの実行

CWキーヤ・ARDFスケジューラ・送信シーケンス(ドレイン電圧ランプダウン後のキャリア遮断順序など)のロジックは、実機なしでホストPC上で高速にテストできます。

```sh
cd app/vhf-am-tx/test
./run_tests.sh
```
